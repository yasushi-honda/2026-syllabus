AIエージェントを選ぼう（AWS登録は対象者のみ）

Week 3 木曜 3・4限
テーマ
各自の契約状況（Claude契約・ChatGPTアカウントの有無）を確認し、使うAIエージェント（Claude Code／Codex CLI／Antigravity CLI）を決める。対象者はAmazon Bedrock経由でClaudeにアクセスできるようAWSに新規登録する
キーワード
Claude Code / Codex CLI / Antigravity CLI / Amazon Bedrock / AWS新規登録 / Use caseフォーム / Budgets
必要な準備
第2回で確認した自分の契約状況（Claude契約・ChatGPTアカウントの有無）。AWSに新規登録する可能性がある人は個人のクレジットカード

この回のゴール

  • 自分の契約状況を整理し、今日から使うAIエージェント（Claude Code／Codex CLI／Antigravity CLI）を決める
  • （対象者のみ）AWSに新規登録し、Free Planの新規特典の条件を理解する
  • （対象者のみ）Amazon BedrockでAnthropicモデルへのアクセスを有効化する
  • AIエージェントがCLIやMCPを通じて外部ツールを操作できる幅の広さを知る

授業の流れ

2コマ連続（90分 + 90分 = 計180分）。途中休憩あり。

1限 前半 約40分

契約状況を確認し、使うAIエージェントを決める

前回の振り返り

  • Google Cloudの$300クレジットは、Claude等のマネージドAPIとして提供される生成AIパートナーモデル（Model as a Service）には使えない——だからこそ今日、Claudeを含むAIエージェントへの接続経路を選ぶ

4つの選択肢を知る

  • 既にClaude契約（Claude Pro等）がある人→ そのままClaude Codeを使う（接続設定は第4回）
  • ChatGPTアカウントがある人→ Codex CLIを使う。まずFreeプランで動作を試し、公式の機能比較表はPlus（$20/月〜）以上のプランのみを対象としているため、動かない場合はPlus以上への加入を検討する
  • いずれの契約もない、またはしたくない人→ Antigravity CLI（agy）——Googleアカウントの認証のみで追加契約不要——を使う（前期から使ってきたもの）
  • Claude Codeを個人契約なしで使いたい人→ AWSに新規登録し、Amazon Bedrock経由で接続する選択肢もある（今日の1限後半〜2限前半で対応）

自分がどれに当てはまるか決める

  • 特定のAIエージェントを使いこなすことがゴールではなく、自分の状況に合ったAIエージェントと協働する経験そのものを大切にする、という本科目の方針を再確認する
迷ったらAntigravity CLIでOK: 前期から使ってきたツールなので、追加の登録や判断に迷う要素がありません。AWS登録やPlus加入で不安がある人は、まずAntigravity CLIで進めても本科目の学びは十分に得られます。
1限 後半 約50分

AWSに新規登録する（対象者のみ）

今日は選んだ経路ごとに進度が分かれる

  • AWS登録の対象者（Claude Codeを個人契約なしで使いたい人）：この時間でAWSに新規登録する
  • 対象外の人（既にClaude契約がある／Codex CLIを選んだ／Antigravity CLIを選んだ）：ChatGPTアカウントのログイン確認や前期のAntigravity CLI環境の見直し等、各自の準備を進めてよい。手が空いたら対象者のサポートに回ってもよい

AWSアカウントを新規登録する

  • aws.amazon.com/free にアクセスし、個人のクレジットカードで新規登録する
  • 登録時に「Free Plan」と「Paid Plan」の選択画面が表示されるので、Free Planを選ぶ（アップグレードしない限り課金されない）
  • 新規登録者には最大$200・6ヶ月間のクレジットが提供される（公式: AWS Free Tier）
過去にAWSアカウントを持っていたことがある人へ: AWS公式規約では新規特典は1人（1エンティティ）につき1アカウントまでとされ、既存のAWSアカウント保有者は対象外です（公式: AWS Free Tier Terms）。クレジットカード番号が判定に使われるかどうかを含め、具体的な判定基準は非公開のため、対象になるかは登録してみないと分かりません。対象外の場合、登録初日から実費（従量課金）が発生します。心当たりがある人は登録前に手を挙げて教員に相談してください。
休憩 10分
2限 前半 約50分

Amazon Bedrockのモデルアクセスを有効化する（対象者のみ）

Bedrockのモデルアクセスを確認する

  • AWSマネジメントコンソールでAmazon Bedrockを開き、モデルカタログからAnthropicのモデルを選ぶ
  • Anthropicモデルは初回のみ利用目的（Use case）フォームの送信が必要（個人開発者は会社ウェブサイトの代わりに、GitHubプロフィールやポートフォリオURL等で代用できる）
  • モデルアクセス自体は既定で有効になっており、フォーム送信後は即座に使えるようになる——「モデルごとに手動でリクエストして承認を待つ」という旧来の手順は不要（公式: Request access to models「Access to the model is granted immediately after use case details are successfully submitted.」）

予算アラート（Budgets）を設定する

  • 第4回でBedrockを実際に呼び出す前に、AWSの予算アラート（Budgets）を低めのしきい値（例: $5）で設定しておく
  • 通知の反映には8〜12時間程度のタイムラグがある点に注意する（公式: Managing your costs with budgets）
対象外の人はこの時間で: Codex CLIを選んだ人はChatGPTアカウントでログインできるか確認、Antigravity CLIを選んだ人は前期の環境（Codespaces・agyの認証状態）を見直しておくと第4回の接続がスムーズです。
2限 後半 約30分

AIエージェントが扱える範囲の広さを知る（教員デモ）

CLIを通じて外部ツールを操作する

  • Google Cloudの操作はgcloud CLI、GitHubの操作はgh CLIを、使用中のAIエージェントから呼び出す——これが本科目の標準パターンになることを教員のデモで見る

MCPを通じて外部ツールを操作する

  • Playwright MCP（公式: microsoft/playwright-mcp）——AIエージェントがブラウザを直接操作し、自分のアプリの動作を確認できる様子をデモで見る（実際に使うのは第13回）
  • clasp（公式: google/clasp）——Google Apps ScriptをローカルからAIエージェント経由で管理する様子をデモで見る。READMEに明記の通りGoogle公式にサポートされる製品ではない点も共有する
今日のポイント: CLIやMCPを通じて、AIエージェントが扱える範囲はターミナルの外——ブラウザ・クラウドサービス・外部ツールにまで広がっています。「AIエージェント＝チャット」という前期までのイメージを、今日で少し更新しましょう。
まとめ 約10分
