対戦ゲームの仕組みを読み解こう

Week 4 木曜 3・4限
テーマ
前回、1人の学生がAIエージェントへの指示だけで実装した「6人同時対戦のリアルタイム対戦ゲーム」を教材に、その裏側の構造をクラス全体で図解しながら読み解き、世界中の誰とでも対戦できるようにするために必要な発想を理解する
キーワード
WebSocket / サーバーとルーム（部屋） / ローカルネットワーク / NAT（ネットワークアドレス変換） / グローバルネットワーク
必要な準備
特になし。実装した本人はプロジェクトを開ける状態にしておくとよい

この回のゴール

  • 1人の学生が作った「6人同時対戦」が、裏側でどんな技術を使っていた可能性が高いかを図解で読み解く
  • サーバー役のPCと、パスコードで区別されるルーム（部屋）の関係を理解する
  • なぜ「学校WiFi内でしか」動かなかったのかを、ローカルネットワークとNATの仕組みから理解する
  • 世界中の誰とでも遊べるようにするには何が必要かを、図解で理解する
今日の位置づけ: 対戦ゲームを実装したのはクラスで1人だけです。今日はその1人の体験を教材に、「AIエージェントがこの種の機能を実装するときに、一般的にどんな技術を使うか」を、実装した本人の説明や図解を通じてクラス全体で理解することが目的です。断定できない部分は「〜という技術が使われていた可能性が高い」という形で扱います。

全員が同じ「学校WiFi」の中にいて、パスコードで同じ部屋（サーバー役のPC）につながっていたと考えられる

サーバーの役割を理解する

  • この図を見ながら、サーバー役のPCが全員の操作（キャラクターの移動・攻撃等）をいったん受け取り、それを全員に配り直す——「ハブ」のような役割を果たしていたと考えられることを確認する
  • 自分の操作が他の人の画面に反映されるまでの流れ: 「自分の操作 → サーバー → 他の全員」という経路をたどっていたと考えられる

「部屋（ルーム）」の意味を考える

  • 同じサーバーの中に複数の対戦グループが同時に存在できるよう、パスコードで「今どの対戦グループに参加しているか」を区別する仕組みが「部屋（ルーム）」だったと考えられる

考えてみる: サーバー役がいなくなったら？

  • 図の中央（サーバー役のPC）が消えたら、まわりの6つの箱はどうなるかを図を指さしながら話し合う
  • サーバーが1台に集中している構造では、その1台が止まると全員が影響を受ける——という弱点に気づく

なぜ「学校WiFi内でしか」動かなかったのか

問いかける

  • 「もし週末に、家から同じ部屋のパスコードを入力してアクセスしようとしたら、うまくいったと思いますか？」

ローカルネットワークとグローバルネットワークの違いを図で見る

  • 家庭のWiFiと学校のWiFiは、それぞれ別の「ローカルネットワーク」（同じルーターの内側の範囲）であることを整理する
Local Network
ローカルネットワーク（前回）
学校WiFi内の6人 → サーバー役のPC
  • 同じルーター（学校WiFi）の内側だけで通信できる
  • NATにより、外部（インターネット）からサーバー役PCへ直接アクセスできない
  • だから家や外出先からは同じ部屋に入れなかった
VS
Global Network
グローバルネットワーク（目標）
世界中の誰でも → 公開されたサーバー
  • インターネット上のどこからでもアクセスできる公開アドレスが必要
  • 個人のPCではなく、誰でも辿り着ける場所にサーバーを置く必要がある
  • これなら家からも、海外からもアクセスできる

NAT（ネットワークアドレス変換）を知る

  • NAT（Network Address Translation、ネットワークアドレス変換）は、ルーターの内側（学校や家の中だけで使うプライベートなアドレス）と外側（インターネット上のグローバルなアドレス）を変換する仕組み（解説: What is NAT (Network Address Translation)?、Fortinet）
  • この仕組みの結果として、ルーターの内側にあるPCは、外部（インターネット）から直接アクセスできない——「This can be useful for preventing attacks that target specific IP addresses or for preventing devices on the internal network from being accessed directly from the internet」（同解説より）
  • だからこそ、サーバー役のPCに学校の外からはたどり着けなかった、と考えられる
余裕があれば: AIエージェントになぜこのゲームは家からは遊べないのですか？と聞いてみて、今日整理した内容と答えが近いか比べてみましょう。

誰でもアクセスできる公開アドレスを持つクラウド上のサーバーなら、ネットワークが違っても同じ部屋に入れる

  • クラウド（Cloud Run等）にサーバーを置くと、インターネット上のどこからでもアクセスできる公開アドレスが手に入る——これが第7回で学ぶCloud Runにつながることを予告する
  • Cloud RunはWebSocket通信にも対応している（公式: Using WebSockets）。ただし接続時間には既定5分・最大60分の上限があり再接続が必要になること、複数のサーバーが同時に動く構成ではプレイヤー情報を共有する仕組み（Firestore等、第9回で学ぶ）が必要になることにも触れておく
