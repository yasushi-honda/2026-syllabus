先輩が訪問する／先輩にインタビューする／ふりかえる

Day 5 全5日間の5日目 / 180分
テーマ
上級生が1年生の教室を訪問して、見てもらい、相談する。先輩の制作のストーリーを、インタビューで聞く。5日間をふりかえる
キーワード
訪問 / 評価・相談 / 希望者の見学 / 制作の時間 / 先輩のインタビュー / AIを使って良かったこと・悪かったこと / 5日間のふりかえり
必要な準備
1年次: 見てもらう制作物と、卒業進級制作の内容。上級生: Day4で更新・新規作成した作品（見せられる状態）。インタビューに答える先輩: 作品を映すパソコン（プロジェクターにつなぐ）。

この回のゴール

  • 1年次: 訪問を受けたチームは、先輩に、自分たちの制作物や卒業進級制作の内容を見てもらい、評価をもらい、相談する。希望すれば、上級生の作品を見に行く
  • 2年次・3年次以上: 希望する人とチーム単位で、1年生の教室を訪問してサポートする（教える側の視点）。訪問しない人は、自分たちの制作を進める
  • インタビューに答える先輩（ハード科など。誰が答えるかは、担当教員が決めて伝える）: 制作のストーリーと、AIを使って良かったこと・悪かったことを、インタビューで話す
  • 5日間のふりかえりを、アンケートに書く
今日のルール: 今日も、順位づけや投票はしません。空いた時間は、Day4で受けた刺激をもとに、それぞれが開発や取り組みを進める時間です。訪問や見学の時間帯の裏で、それぞれが制作を続けてよい。なお、今日の流れは、Day4の様子に応じて、変更することがあります。

授業の流れ

2コマ連続（90分 + 90分 = 計180分）。1限は「今日の説明・準備15分 → 上級生の訪問40分 → 制作35分」、2限は「希望者の見学40分 → 制作15分 → 先輩のインタビュー25分 → アンケート10分」。1限と2限のあいだに休憩10分（授業時間に含めない）。

1限 最初 約15分

今日の説明をする／それぞれ準備をする

今日の説明（約5分）

  • 担当教員が、今日の流れ（訪問・見学・制作・インタビュー・アンケート）と、場所・時間を説明する
  • 上級生は、訪問する人を決める（希望する人とチーム単位で、一部が行く。人数は、担当教員が調整する）

それぞれの準備（約10分）

  • 1年次: 見てもらう制作物と、卒業進級制作の内容を、すぐ見せられるようにする。聞きたいこと・相談したいことを、1つ以上、決めておく。Day4のふりかえりフォームに書いた、「活かしたいこと」も思い出す
  • 2年次・3年次以上: 訪問する人は、1年生に聞くこと・伝えることを考える。訪問しない人は、作品を見せられる状態にする（Codespacesで動かすチームは、Codespacesを再開→npm start→8000番をPublic。Unityなど、別の方法で見せるチームは、その方法で準備する）
  • インタビューに答える先輩: 下のインタビューの質問を、チームで確認し、答えをメモしておく。作品を映すパソコンを確かめる
1限 前半 約40分

上級生が、1年生の教室を訪問する

  • 1年次: 訪問を受けたチームは、先輩に、自分たちの制作物と卒業進級制作の内容を見てもらう。評価（よいところ・直したいところ）をもらい、相談する
  • 訪問する上級生: 1年生の話を聞き、触って、感想や助言を伝える。3年次以上は、答えを言い切らず、気づいてもらうつもりで話す。2年次は、うまく動かないときの切り分けを手伝う
  • 訪問に行かない上級生（インタビューに答える先輩を含む）・訪問を受けていない1年生: 自分たちの制作を進める（裏で制作）

1限 後半 約35分

制作の時間（Day4・訪問の刺激をもとにする）

訪問で出た評価や相談、Day4で受けた刺激を、作品や取り組みに取り入れる時間。進め方は、これまでと同じ。1回に1つの変更を、「頼む→動かす→確かめる」で繰り返す。

  • 1年次: もらった評価や助言を、小さな変更1つから試す。卒業進級制作の相談があれば、その続きをする
  • 2年次・3年次以上: 自分たちの作品や、卒業進級制作を進める。1年生に聞かれたことを、作品に活かしてもよい
  • インタビューに答える先輩: 自分たちの作品を進める。インタビューで見せる画面を整える
  • agyに制限がかかったチームは、Day3の「agyに『制限がかかった』と表示されたとき」の手順で、別のGoogleアカウントに切り替える（Day3の手順）
休憩 10分
2限 前半 約40分

1年生の希望者が、上級生の教室へ見に行く

  • 1年次（希望者だけ）: 上級生が、Day4で更新した作品・新しく作った作品を、見に行く。触って、質問する。行くかどうかは、自由（行かなくてよい）
  • 上級生: 作品を見せられる状態にして、来た1年生に見せて、質問に答える（Day4と同じ）。来る人が少ない間は、制作を続ける。インタビューに答える先輩は、このあとのインタビューの準備を始めてもよい
  • 行かない1年次: 自分たちの制作を進める（裏で制作）。見学に行った人は、戻ってから、聞いたこと・活かせそうなことを、チームに共有する

2限 中盤 約15分

制作の時間／インタビューの準備と移動

  • インタビューに答える先輩: 作品を映すパソコンを持って、1年生の教室へ移動し、プロジェクターにつなぐ。映る画面を、確かめる。個人情報（通知・ほかのタブ・名前など）が映らないようにする
  • 1年次: 席に戻り、見学で聞いたことを、チームに共有する。インタビューで聞いてみたいことがあれば、メモしておく
  • 上級生（インタビューに答える先輩を除く）: 自分たちの作品を進める。5日間でやったことを、短くメモしておく（アンケートで使う）
2限 後半 約25分

先輩のインタビュー（1年生の教室）

プレゼンの時間は取らず、教員からのインタビューに答える形にする。答える先輩（ハード科などを予定。担当教員が決めて伝える）は、前に立ち、作品をプロジェクターに映しながら答える。質問は、事前に伝えてある。1年生は、聞いて、最後に質問もできる。

インタビューの質問（事前に、答える先輩に伝える）

  1. 作ったものと、作られるまでのストーリー何を作りましたか。作ろうと思ったきっかけと、作られるまでのストーリーを教えてください。
  2. 役割分担チームの役割分担は、どうしましたか。
  3. AIへの頼み方AIには、最初にどう頼みましたか。途中で、頼み方を変えたことはありますか。
  4. AIを使って良かったことAIを使って、良かったことは何ですか。
  5. AIを使って困ったこと・悪かったことAIを使って、困ったこと・悪かったことは何ですか。どう立て直しましたか。
  6. もう一度作るならもう一度作るなら、何を変えますか。
  7. 1年生へ1年生に、伝えたいことを一言お願いします。
■ 先輩へのインタビューの質問
1. 何を作りましたか。作ろうと思ったきっかけと、作られるまでのストーリーを教えてください。
2. チームの役割分担は、どうしましたか。
3. AIには、最初にどう頼みましたか。途中で、頼み方を変えたことはありますか。
4. AIを使って、良かったことは何ですか。
5. AIを使って、困ったこと・悪かったことは何ですか。どう立て直しましたか。
6. もう一度作るなら、何を変えますか。
7. 1年生に、伝えたいことを一言お願いします。
  • 時間は、1問あたり3分ほど。最後の約2分は、1年生からの質問を受ける。時間が足りないときは、質問を絞ってよい（担当教員が決める）
  • 個人情報や、答えたくないことには、答えなくてよい。画面に、個人情報やAPIキーを映さない
  • 1年次: 聞きながら、自分たちの制作に活かせそうなことを、メモする
まとめ 約10分

5日間のふりかえりアンケート／片付け

アンケートに答える（Googleフォーム、約6分）

  • フォームは、この講座のGoogle Classroomの専用ルームで共有される。5日間を通して、学んだこと・うまくいったこと・難しかったこと・これから活かしたいことを書く

片付けチェック（約4分）

授業の中で終わらない場合は、下の「課題・次回までにやること」の手順で、授業のあとに確認する。

  1. 変更があれば、プッシュしたGitHubで、ファイルが見えることを確認する。
  2. ポートの公開をやめた（またはサーバーを止めた）Publicのままにしない。
  3. Codespacesを停止した見本ゲーム用・Battle Base用・Day1のチーム用、すべて github.com/codespaces で停止済みか確認する。
  4. 作ったものの扱いを決めたリポジトリを、そのまま残す／消すのどちらかに、チームで決める。見本ゲームをForkしたものは、Publicのままで、あとから変えられない（Day1と同じ。公式: About forks）。自分で新しく作ったリポジトリは、Privateにもできる。残すなら、個人情報・APIキーが無いことを、もう一度確認する。

安全のこと（Day3・Day4と同じ）

  • Publicにすると、URLを知っている人は、ログインなしで入れる。部屋のパスコードや合言葉は、本物のアクセス制限にはならない
  • 名前は、本名ではなくニックネーム。個人情報・APIキーは、画面にも、ファイルにも入れない（プロジェクターに映す画面も同じ）
  • 想定外の参加者が入ったときは、部屋を作り直す
