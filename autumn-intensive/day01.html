GitHubとCodespacesの基本を知り、全員で一度開いて閉じる

まず言葉を整理する

手順（教員の画面を見ながら、チーム全員で同じ手順を一斉に進める）

  1. 全員: GitHubにログインする登録がまだの人は github.com/signup から新規登録する。登録後、メールの確認（verify）を済ませる。教員が個別にフォローする。
  2. 代表者: チームのリポジトリを作るGitHub右上の「+」→「New repository」を選び、Repository name にチームの名前（例: team-app）を入力する。Privateを選び、「Add a README file」にチェックを入れて「Create repository」をクリックする（最初のコミットがないと、Codespacesを作る元のブランチがない）。（公式: Creating a new repository）
  3. 代表者: チームのメンバーを招待するリポジトリの「Settings」→「Collaborators」→「Add people」で、メンバーのGitHubアカウントを追加する。招待を受けた人は、届いたメールから承認する（公式: Inviting collaborators to a personal repository）。
  4. 全員: 自分のアカウントでCodespacesを開くチームのリポジトリを開き、「Code」ボタン→「Codespaces」タブ→「＋」で作る。ブラウザ上にVS Codeの画面が立ち上がれば成功。左にファイル一覧、真ん中にエディタ、下にターミナルがある。作成時のダイアログ下部に「誰が支払うか」のメッセージが出るので確認する（公式: Creating a codespace for a repository）。
  5. 全員: 確認できたらすぐ停止するgithub.com/codespaces を開き、一覧のCodespaceの「…」→「Stop codespace」を選ぶ（公式: Stopping and starting a codespace）。削除はしない。保存した変更は、次に起動したときも残る。
なぜ全員が開いて閉じるのか: 起動している間は、その人の無料枠の時間が減ります。開いたらすぐ停止する習慣をつけるためです。もう1つの理由は、代表者のCodespacesの無料枠が尽きたとき、交代要員が自分のアカウントで続けられるようにするためです。

無料枠を確認し、交代要員を決める

  • 各自 github.com/settings/billing の「Codespaces」欄で、今月の使用状況を確認する（公式: GitHub Codespaces billing）。他の授業でも使っている人は、特に注意する
  • GitHub Freeの無料枠は月120時間分（2-coreマシンでは実質60時間相当）。使い切って支払い方法が未登録だと、Codespacesを新たに起動・再開できなくなる
  • 枠に余裕のあるメンバーを、交代要員として決めておく。止まったときの回避策は、授業概要の「無料枠の注意」を参照する

agyを導入し、ポート転送でPublicに公開してみる

ここからは代表者のCodespacesを使う

代表者は、1限後半に作って停止したCodespacesを、github.com/codespaces の一覧からCodespacesの名前をクリックして再開する（停止して再開する練習にもなる）。他のメンバーの練習用Codespacesは、停止したままにしておく。ドライバーを交代しながら、全員が一度はキーボードを持つ。

Antigravity CLI（agy）を導入して認証する

  1. インストールするCodespacesのターミナルに次のコマンドを貼り付けてEnter（公式: Antigravity CLI — Installation & auth）。 
    curl -fsSL https://antigravity.google/cli/install.sh | bash
    終わったら agy --version と入力してEnter。バージョン番号が表示されれば成功。
  2. 認証するターミナルで agy と入力してEnter。表示された認可URLを、Ctrlキー（Macの場合はCmdキー）を押しながらクリックして新しいタブで開き、Googleアカウントでサインインする。表示された英数字のコードをコピーし、ターミナルに戻って貼り付けてEnter。
  3. 認証できたか確認するヘッダーにメールアドレスが表示されれば認証完了。話しかけてみる（例: あなたが何をできるか、自己紹介してください）。
つまずいたとき: 認可URLが出ない → もう一度 agy と入力する。コードを貼ってもエラー → 前後に余分な空白や改行が入っていないか確認してコピーし直す。時間がかかりすぎる → Ctrl+C で中断して、agy から最初からやり直す。それでも動かなければ手を挙げる。agyの無償枠には利用制限があります。上限に達したら、チーム内で待つ・使う頻度を調整してください。

ポート転送を「Public」にして、公開URLで開く

まず、公開確認用の小さなページを作る。agyに頼んでもよいし、教員がサンプルを示してもよい。

index.html を作って、「こんにちは、チームのみんな」と大きく表示する1枚のページにしてください。

トラックを選び、最初の「動くもの」を作る

チームで相談して、トラックを選ぶ

作って、確認して、記録する

  • ドライバーがagyに指示を入力し、ナビゲーターが結果を確認する。うまくいかないときは、何を押したら何が表示されたかをagyにそのまま伝える
  • ポートの設定は前のブロックと同じ。python3 -m http.server 8000 で動かして確認する
  • できたら、変更をGitHubに記録する。プッシュしないと、Codespacesの中にしか残りません。交代要員が引き継ぐためにも必要
ここまでの変更をコミットして、GitHubにプッシュしてください。
トラックAの人へ（撮影・個人情報のルール）: カメラを使うと、他人を撮影する場面が出ます。撮影前に必ず声をかけて同意を得てください。撮った映像・画像を無断で公開・共有しないでください。カメラは、ブラウザが許可を求める画面で「許可」を選ぶと使えます（公式: MDN getUserMedia）。http:// のページでは、カメラが使えません。
