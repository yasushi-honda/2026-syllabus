## 8. 授業概要
- 前期「AI活用プログラミング基礎」でNotebookLM（現Gemini Notebook）を使って「自分だけのAI」を育てた経験を土台に、指示を受けて自分で作業を進める **AIエージェント** と協働する実践中心の科目です。
- 最初はブラウザだけで完結する **Google AI Studio の Build mode** で、GitHubと連携した簡単なミニアプリづくりを通じて「指示したら形になった」という **コンパクトな成功体験** を積みます。
- 続いて、GitHub Codespaces上で動く **Antigravity CLI（agy）** を導入し、ターミナルで自然言語の指示を出しながらAIエージェントと協働する体験へ段階的にレベルアップします。
- 学期後半では、各自が並行して取り組む **進級制作** にAIエージェントをどう活かせるかを検討し、実際に小さな改善を加える取り組みへつなげます（前半で作った個人開発の延長として続けることも選べます。進度は一人ひとりの状況に応じて柔軟に調整します）。
- GitHubアカウント・リポジトリの基本操作は前期の他授業で触れている前提で進めますが、理解度には個人差があるため第2回で丁寧に再確認します。**GitHub Codespaces** は本科目で初めて使う学生が多い前提で、導入から丁寧にサポートします。
- 引き続き、Googleアカウントがあれば無料枠から使い始められるツールを中心に扱います。Antigravity CLIの無料枠は時期によって変動する可能性があるため、都度公式情報で確認しながら進めます。
- 中間・期末に発表の機会を設け、自分が作ったもの・取り組んだプロセスを自分の言葉で伝える経験を積みます。

## 9. 到達目標

### 知識・理解
1. 「チャット型AI」と、指示を受けて自分でタスクを進める「AIエージェント」の違いを自分の言葉で説明できる。
2. Google AI Studio の Build mode の基本的な使い方（アプリ作成・GitHub連携・APIキーの自動設定）を理解している。
3. Antigravity CLI（agy）の基本的な使い方（インストール・認証・自然言語での指示）を理解している。
4. GitHubの基本操作を前期までの学びを踏まえて再確認し、GitHub Codespaces・GitHub Pagesの役割を新しく理解している。
5. AIエージェントが生成した成果物にも確認・検証が必要であることを理解している。

### 思考・判断
1. 自分の目的に応じて、Google AI Studio Build modeとAntigravity CLIのどちらを使うかを判断できる。
2. AIエージェントに任せる部分と、自分で確認する部分を場面に応じて切り分けられる。
3. 自分の進級制作のどこにAIエージェントを活かせるかを考えられる。

### スキル・表現
1. Google AI Studio Build modeで、GitHubと連携した簡単なアプリを作成できる。
2. Antigravity CLI（agy）を使い、自然言語の指示で小さな機能を実装できる。
3. 自分が作ったもの・取り組んだプロセスについて、自分の言葉で発表できる。

### 関心・意欲・態度
1. 新しいAIツールに対して臆せず試してみる姿勢を持つ。
2. うまくいかないときも投げ出さず、小さく試行錯誤を続ける。
3. 自分のペースを保ちながら、必要に応じて仲間や教員に相談する。

## 10. 授業計画（全14回）

| 週 | テーマ | 主な内容・活動 |
|:---:|:---|:---|
| 1 | **前期振り返り＆後期オリエンテーション** | 前期に育てた自分のNotebookLM（現Gemini Notebook）を見返し、これまでの取り組みを振り返る。「聞けば答えてくれるチャット型AI」と「指示を受けて自分でタスクを進めるAIエージェント」という新しい軸を知る。後期14回の流れを俯瞰し、評価方法を確認する。 |
| 2 | **GitHubを再確認し、Codespacesを使ってみよう** | GitHubアカウント・リポジトリの基本操作を短時間で再確認する（前期の他授業で触れた内容の復習、理解度の個人差に配慮）。続けて、本科目で新しく使うGitHub Codespacesを教員のデモに沿って実際に起動し、ブラウザだけで開発環境が立ち上がる仕組みを体験する。作った成果物を公開するGitHub Pagesの仕組みも合わせて紹介し、後半の制作で迷わないための土台を整える。 |
| 3 | **Google AI Studio Build modeに触れてみよう①** | Google AI Studio の Build modeを開き、GitHubリポジトリを新規作成、または既存リポジトリをインポートする。自然言語の指示で、ブラウザだけで動く簡単なミニアプリ（例：自己紹介カード、簡易クイズ等）の土台を作る。アプリ作成時に自分のGemini APIキーが自動でシークレットとして設定される仕組みも確認する。 |
| 4 | **Google AI Studio Build modeで仕上げよう②** | 第3回で作ったミニアプリを自然言語の追加指示で改善し、GitHubへプッシュして公開する。「指示したら形になった」というコンパクトな成功体験を、自分の言葉でひとことメモに残す。 |
| 5 | **Antigravity CLI（agy）を導入しよう** | GitHub Codespaces上にAntigravity CLI（agy）をインストールし、Googleアカウントで認証する。教員のデモでAIエージェントがターミナル上で自然言語の指示を実行していく様子を観察する。無料枠は時期によって変動し得ることを公式情報とあわせて確認する。 |
| 6 | **agyと一緒につくる①** | 自分の個人プロジェクト（第3〜4回の続き、または新規）に、agyへの自然言語の指示で小さな機能を1つ追加する演習。 |
| 7 | **agyと一緒につくる②** | 第6回の続き。改善・仕上げを行い、GitHub Pagesで公開する。取り組みの過程で気づいたことを振り返りメモに残す。 |
| 8 | **🎤 中間共有会** | 自分が作った成果物とAIエージェントとのやり取りを5分程度で共有し、質疑応答を行う。完璧さより「やってみた」経験の共有を重視する。 |
| 9 | **進級制作とAIエージェントをつなげよう** | 各自が並行して取り組む進級制作の現状を共有し、AIエージェント（agyまたはAI Studio Build mode）をどこに活かせるかを計画する。前半で作った個人開発の延長として続けることも選べる。進度は一人ひとりの状況に応じて柔軟に調整する。 |
| 10 | **進級制作に小さな改善を加える①** | 第9回の計画に基づき、進級制作（または個人開発の延長）に小さな改善を1つ実装する。 |
| 11 | **進級制作に小さな改善を加える②** | 第10回の続き。改善を積み重ね、動作確認とコミット・プッシュまで行う。 |
| 12 | **仕上げ①** | 取り組んできた成果物の最終調整。 |
| 13 | **発表準備** | 発表用の資料・メモ作りに着手。 |
| 14 | **🎤 最終発表会＆総括** | 自分の取り組みとAIエージェントとの協働プロセスについて発表。前期からの学びを振り返る。 |

※授業計画は、学生の理解度や進度に応じて柔軟に変更する可能性があります。特に第9〜11回の進級制作との接続部分は、クラス全体の状況を見ながら調整します。
※毎回の授業冒頭で、AI関連の最新ニュース・トピックを共有します。

## 13. 評価方法・基準
AIエージェントとどれだけ主体的に協働し、実際に動くところまで仕上げられたかを重視します。「上手か下手か」ではなく「どれだけ取り組んだか」を評価します。

| 配分 | 項目 | 内容 |
|---|---|---|
| 30% | AIエージェントとの協働プロセス | Google AI Studio Build mode / Antigravity CLIでの試行錯誤、指示の工夫。 |
| 25% | 制作物の完成度 | ミニアプリ・進級制作への改善実装など、実際に動くところまで仕上げられたか。 |
| 20% | AI出力の確認・検証の習慣 | AIエージェントの生成物を自分で動かして確かめる姿勢。 |
| 15% | 発表への取り組み | 中間・最終発表への参加姿勢。完璧さより「自分の言葉で伝えようとする姿勢」を評価。 |
| 10% | 主体性・基本操作 | 授業への積極的参加、GitHub・Google AI Studio・Antigravity CLI等の基本操作習得。 |
