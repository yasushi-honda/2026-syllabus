## 7. 授業概要
- 前期「AIコミュニケーション基礎」の続きとなる科目です。前期で育てた「自分だけのAI」（**Gemini Notebook**、旧NotebookLM）を土台に、AIとのコミュニケーションをさらに深めます。
- 後半の柱は**AIエージェントとの協働**です。GitHub Codespaces上のターミナルで**Antigravity CLI（agy）**を使い、自然言語で指示を出しながらWebページやアプリが形になっていく過程を体験します。
- 「チャット型AI」（Gemini Notebook・AI Studio Build）と「エージェント型AI」（agy）、それぞれとの関わり方の違いを体感し、言語化します。
- agyは全員が触れます。目指すのは高度な技術習得ではなく、**自然言語での対話を重ねながら小さな成功を積み上げ、AIとコミュニケーションを取ることへの自信を持つこと**です。
- 第9〜13回では、agy・AI Studio・Gemini Notebookを自由に組み合わせ、自分が作りたいものをAIとの対話で形にする個人制作に取り組みます（テーマは各自自由）。
- 第14回では簡単な発表会を行い、AIエージェント時代のコミュニケーションについて振り返ります。

## 8. 到達目標

### 知識・理解
1. Gemini Notebook（旧NotebookLM）、AI Studio Build、Antigravity CLI（agy）それぞれの特徴と役割の違いを説明できる。
2. GitHub Codespacesの基本操作、ターミナルでのコマンド実行の考え方を理解している。
3. AIエージェントが自然言語の指示を受けてタスクを進める仕組みの概要を説明できる。
4. 曖昧な指示と明確な指示で、AIエージェントの動きがどう変わるかを説明できる。
5. チャット型AIとエージェント型AIそれぞれの得意・不得意を説明できる。

### 思考・判断
1. 自分が作りたいものをAIエージェントに伝わる形に言語化できる。
2. AIエージェントの出力（コード・動作）を確認し、意図通りかを判断できる。
3. 意図通りに動かない場合、伝え方のどこに問題があったかを推測し、指示を改善できる。
4. AIとの対話を振り返り、「どう伝えたら何が引き出せたか」を言語化できる。

### スキル・表現
1. GitHub Codespacesを起動し、ターミナルでAntigravity CLI（agy）を実行できる。
2. 自然言語での指示を重ね、AIエージェントと協働して作品を育てられる。
3. Gemini Notebook・AI Studio Build・agyを目的に応じて使い分けられる。
4. 自分とAIとのやりとりの記録を、他者にわかりやすく共有できる。

### 関心・意欲・態度
1. 慣れないターミナル操作やAIエージェントとの対話に、失敗を恐れず挑戦する。
2. 小さな成功体験を積み重ね、AIとのコミュニケーションに自信を持つ。
3. 他者のAIとの関わり方から学ぼうとする姿勢を持つ。

## 12. 評価方法・基準
成果物の完成度だけでなく、AIエージェントとの対話をどれだけ重ね、伝え方を改善しながらコミュニケーション力を高められたかを重視します。

- **25%** AIエージェントとの協働プロセス — agyとの対話を重ね、伝え方を改善しながら作品を育てられたか。
- **20%** 成果物・公開実績 — 個人制作（第9〜13回）の完成度、公開できているか。
- **15%** コミュニケーション力の向上 — 曖昧な指示から明確な指示への改善、対話ログの言語化。
- **15%** Gemini Notebookの継続活用 — 自分のAIをさらに育てられたか。
- **15%** 相互レビューへの参加・貢献 — 中間レビューでの共有・フィードバック。
- **10%** 主体性 — 慣れない環境への挑戦、粘り強さ。
