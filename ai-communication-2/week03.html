ターミナルってなんだろう？

Week 3 火曜 3・4限
テーマ
ls・cd・pwd等の基本コマンドを試しながら、ターミナルの使い方とディレクトリ（フォルダ）構造の考え方を学ぶ。agyが裏側でファイルを操作している「場所」を自分の手でも確かめる回
キーワード
ターミナル / pwd / ls / cd / ディレクトリ構造 / 絶対パス・相対パス
必要な準備
第1回・第2回で使用したリポジトリ・Codespaces環境にアクセスできる状態（見当たらない場合は担当教員に確認）

この回のゴール

  • pwdで「今どこにいるか」を確認できる
  • lsで「その場所に何があるか」を一覧表示できる
  • cdで別のディレクトリに移動できる
  • ディレクトリが「フォルダの中にフォルダ」という木構造になっていることを、自分の言葉で説明できる
  • agyがファイルを作成・編集したとき、ターミナルで場所と結果を自分で確認できる

授業の流れ

2コマ連続（90分 + 90分 = 計180分）。途中休憩あり。

1限 前半 約40分

「agyは裏で何をしているのか」という疑問から、今日のテーマへ

前回の振り返り（10分）

  • 第2回で学習ガイドを使いAntigravity CLI（agy）の仕組みを理解し、Codespacesを再開して改めてagyに触れたことを思い出す
  • agyに「簡単な自己紹介ページを作って」と頼むと、実際にファイルが作られコードが書かれたことを振り返る

「それはどこに、どうやって？」という疑問（10分）

  • agyが作ったファイルはどこに保存されているのか、どうやって「そこ」を見つけて作業しているのかを問いかける
  • ペアで「見当がつくか」を話し合う（正解を出す必要はない、疑問を持つことが目的）

今日の全体像を知る（20分）

  • ターミナルは「文字で操作するコンピュータの窓口」——ファイルエクスプローラーでマウスを使ってやることを、文字のコマンドでやる場所であることを共有する
  • 今日はpwd・ls・cdという3つの基本コマンドを使い、ターミナルの中で自分が「今どこにいて」「何があって」「どう動けるか」を確かめていく
  • 前回・前々回で使用したリポジトリを開き、停止していたCodespaceを再開（resume）する——「Create codespace」で新規作成しない
  • 画面下部のターミナルパネルの位置を再確認する（無ければCtrl + `または「表示」→「ターミナル」）
1限 後半 約50分

基本コマンド3つを手で打つ：pwd・ls・cd

pwd——今どこにいるかを確認する（10分）

  • ターミナルにpwd（print working directory）と打ってEnter。表示された文字列が「今自分がいる場所（カレントディレクトリ）」であることを確認する
  • この文字列をパスと呼ぶことを紹介する

ls——そこに何があるかを見る（15分）

  • ls（list）と打つと、今いる場所にあるファイルやディレクトリの一覧が表示されることを確認する。index.htmlやlist.html等、これまでの授業で作ったファイルが見えるはず
  • ls -laを試し、lsだけでは見えない「隠しファイル」（.で始まるファイル、.gitなど）や、ファイルの詳細情報も表示されることを紹介する（今日は「こういう情報も見える」と知るだけでよい）

cd——別の場所に移動する（20分）

  • cd（change directory）の後にディレクトリ名を続けると、そこに移動できることを確認する。プログラム基礎の授業で使っているリポジトリに、週ごとのディレクトリ（week01/等）があればcd week01で移動し、pwd・lsで確認する
  • cd ..——1つ上の階層に戻る特別な書き方。移動後、再度pwdで今どこにいるか確認する
  • 演習：cdで2〜3か所を移動し、その都度pwd・lsで「今どこにいて、何があるか」を確認する。迷子になったらcdだけ（引数なし）でホームディレクトリに戻れることも紹介する
ターミナルは「今いる場所」を常に持っている: ファイルエクスプローラーで今どのフォルダを開いているか目で見えるのと同じように、ターミナルも「今いる場所（カレントディレクトリ）」を内部に持っています。pwdはそれを文字で見せてくれるコマンドです。
休憩 10分
2限 前半 約50分

ディレクトリの木構造と、agyの動きをターミナルで追う

ディレクトリは「フォルダの中にフォルダ」の木構造（15分）

  • Googleドキュメントに、リポジトリのディレクトリ構造を木の絵で描いてみる（一番上がリポジトリのルート、その下にweek01/等の枝が伸びる。参考までに、ホワイトボードなど教室にある物理的な道具を使ってもよい）
  • 絶対パス（ルートから見た完全な道順）と相対パス（今いる場所から見た道順）の違いを、木の絵を指しながら説明する
  • mkdir（make directory）で新しいディレクトリを1つ作ってみる。lsで増えたことを確認する

agyに指示を出し、ターミナルで結果を追う（30分）

  • pwdで今の場所を確認してから、agyに次のように依頼する： 
    自己紹介を書いたREADME.mdというファイルを作ってください
  • agyの応答が終わったら、agyに頼らず自分の手でlsを打ち、README.mdが増えていることを確認する
  • cat README.md（catはファイルの中身をそのまま表示するコマンド）で、agyが書いた内容をターミナルで直接読む
  • 観察ポイント：agyは「今いるディレクトリ」を基準にファイルを作っている——今日はじめて確認する「agyはワークスペースを起点に作業する」という仕組みが、実際のファイルの場所として目に見える形で確認できる

気づきをメモする（5分）

  • 「agyが裏で何をしていたか、今日で分かったこと」を1つメモに残す
agyも「今いる場所」から作業している: 公式ドキュメント（Getting Started）にある通り、agyは起動したディレクトリ（ワークスペース）を基準にファイルを読み書きします。今日pwd・lsで確認した「場所」の感覚は、agyの動きを理解するための土台になります。
2限 後半 約30分

演習：ディレクトリを作り、agyと一緒にファイルを増やす

一連の流れを自分の手で行う

  • mkdirで自分の好きな名前の新しいディレクトリを作る
  • cdでそのディレクトリに移動し、pwdで今の場所を確認する
  • agyに「このディレクトリに、好きな一言を書いたメモファイルを作って」のように依頼する
  • lsでファイルが増えたことを確認し、catで中身を読む
  • cd ..で元の場所に戻り、pwdで確認する

余裕があれば

  • さらにもう1段階、ディレクトリの中にディレクトリを作り、木構造が深くなる様子をpwdの表示の変化で確認する
まとめ 約10分

  • 今日のキーワード「pwd」「ls」「cd」「絶対パス・相対パス」を口に出して言えるか確認して退出
