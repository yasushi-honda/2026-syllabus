AIエージェントの文脈でGit/GitHubを知る意味を理解する

AIエージェントとGitの関係

  • AIエージェント自体は、Gitリポジトリでなくても動作できる汎用的な仕組み。ただし本科目では、リポジトリを元に作られるクラウド開発環境GitHub Codespaces（中でGitリポジトリを直接操作できる）でAntigravity CLI（agy、第5回から）を使う
  • チャット型AIとの決定的な違いは、指示を受けて実際にファイルへ変更を加える点にある
  • Gitは変更を自動で記録する仕組みではない。ステージング・コミットという操作をして初めて、変更が履歴として残る——これは人間（あるいは人間の指示を受けたAIエージェント）が意図的に行う操作

だからこそGit/GitHubの理解が土台になる

  • コミットという記録の仕組みを理解していれば、AIエージェントが行った変更を後から確認できる
  • 意図しない変更があった場合に、コミット単位で元に戻せる
  • 複数人（人間同士、あるいは人間とAIエージェント）が同じプロジェクトで安全に共同作業できる
今日はまだ手を動かしません: ここまでは考え方の説明です。実際にAIエージェントと一緒に手を動かすのは第5回からです。今日は「なぜGit/GitHubを学ぶ必要があるのか」を理解するだけで十分です。

Gitの基本を知り、GitHubアカウントを登録する

Gitとは何か

  • Gitは、最も人気の高い分散型バージョン管理システム。プロジェクトの変更・決定・進行状況の全体的な履歴を1か所で確認できる仕組み（公式: About Git）

GitHubへプッシュ
  • コミット——変更の状態を記録するスナップショット。写真を撮るようなもの
  • ブランチ——複数の作業ラインを並行して進められる仕組み

GitHubとは何か

  • GitHubは、Gitリポジトリをホスティングするプラットフォーム。Issue・プルリクエスト・コードレビューといった、共同作業のための機能を提供する
  • つまり「Git＝仕組み」「GitHub＝それを使ってオンラインで共同作業する場所」という関係

GitHubアカウントを準備する

  • すでに前期の他授業等でGitHubアカウントを持っている人は、そのアカウントでログインして使う（新規登録し直す必要はない）
  • 持っていない人は、github.com/signup にアクセスし、画面の案内に沿って新規登録する。登録後の初期設定の詳細は公式ガイド（Getting started with your GitHub account）を参照
  • 新規登録する場合は、強固で他で使い回していないパスワードを設定する
  • 登録後、メールアドレスの確認（verify）を行うと全機能が使えるようになる
  • 安全のため、まだ設定していなければ2段階認証（2FA）の設定が強く推奨されている
  • プランはGitHub Freeで十分（後から変更も可能）

組織アカウントを知り、Codespacesの仕組みを知る

組織アカウント（Organization）を知る

  • Organizationは、複数人が共同でプロジェクトに取り組むための共有アカウント。公式には「ビジネスやオープンソースプロジェクトが多数のプロジェクト間で協力できる共有アカウント」と説明される（公式: About organizations）
  • 個人アカウントが前提となる仕組みで、それぞれが自分の個人アカウントでログインしたまま、同じOrganizationに参加して共同作業する
  • メンバーごとに役割（ロール）を割り当てて、アクセス権限を細かく管理できる
  • GitHub Freeのままでも無料でOrganizationを作成できる（一部のプライベートリポジトリ機能には制限あり）
  • 今日は説明だけにとどめ、実際の作成は行わない。複数人で1つのプロジェクトに取り組む場面（学校の内外を問わず）で使われる仕組みとして知っておく

GitHub Codespacesの仕組みを知る

  • 教員が用意したリポジトリからGitHub Codespacesを起動する様子をデモで見せる——ブラウザだけで開発環境が立ち上がる仕組みを観察する
  • 作った成果物を公開するGitHub Pagesという仕組みがあることも一言紹介する（実際に使うのは第4回）
今日は見るだけでOK: 自分のリポジトリを作ってGitHub Codespacesを起動するのは第3回からです（Google AI Studioでリポジトリを新規作成、またはインポートします）。今日は「こういう仕組みで開発環境が立ち上がる」ということを知るだけで十分です。
