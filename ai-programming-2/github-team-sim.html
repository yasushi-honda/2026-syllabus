Week 5 練習用
これは練習用のシミュレーションです。本物のGitHubやagyには接続していません。入力した内容はどこにも送信・保存されません（ページを再読み込みすると最初からやり直しになります）。
チーム「ゲーム作り班」の一員になって、clone → ブランチ → コミット → push → PR → マージ、そしてコンフリクトの解消までを、コマンドとagyへの自然言語のお願いの両方で体験します。第5回の授業計画に戻る

🎉 全ミッションクリア！

チーム開発の一通りの流れを体験できました。同じ操作を「コマンド」と「agyへのお願い」で比べてみましょう。

やりたいことコマンドagyへのお願いの例
リポジトリを手元に取得git clone URL「このリポジトリをcloneして」
作業用のブランチを作るgit switch -c add-title「add-titleというブランチを作って」
変更を記録するgit add . → git commit -m "..."「変更をコミットして」
GitHubに送るgit push -u origin ブランチ名「pushして」
PRを作るgh pr create（または画面のボタン）「PRを作って」
mainの最新を取り込むgit pull origin main（環境によっては git pull --no-rebase origin main）「mainの最新を取り込んで」
コンフリクトを直すファイルを開いて印（<<<<<<<など）を消し、git add → git commit → git push「両方残して解消して」（どれを残すかは自分で決めて伝える）

気づいたこと: agyに頼んでも、多くの場合、裏ではgitやghのコマンドが実行されます。何が起きているかを読めることが、AIに任せるときの安心につながります。
