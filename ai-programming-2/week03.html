GitHubの続き＋Codespacesを自分で起動＋agyを導入しよう

Week 3 木曜 1・2限
テーマ
GitHubアカウント登録を完了させ、授業用リポジトリをフォークしてGitHub Codespacesを自分で起動し、Antigravity CLI（agy）を導入して最初の指示を出す
キーワード
GitHub / フォーク / GitHub Codespaces / Antigravity CLI（agy）/ 認証 / AIエージェント
必要な準備
第2回で準備したGitHubアカウント（ログインできる状態）。まだ登録・確認が終わっていない人は、今日の1限前半で個別にフォローするのでそのまま来てください。

この回のゴール

  • 前回終わらなかったGitHubアカウント登録を完了し、全員がログインできる状態にする
  • 授業用リポジトリを自分のアカウントにフォークする
  • GitHub Codespacesを自分の手で起動する
  • Codespaces上にAntigravity CLI（agy）をインストール・認証する
  • agyに自然言語で指示を出し、最初の変更を自分の目で確認する

授業の流れ

2コマ連続（90分 + 90分 = 計180分）。途中休憩あり。

1限 前半 約40分

前回の続き——GitHubアカウントを全員そろえる

前回の振り返り

  • Git（バージョン管理・コミット・ブランチ）とGitHub（Gitをホスティングするプラットフォーム）の関係を1分で振り返る
  • AIエージェントが指示を受けてファイルに変更を加える存在であり、その変更をGitが記録する——という前回の要点を再確認する

アカウントの状態ごとに個別フォローする

  • ログインできる人：待たずに次の「1限後半」のフォーク作業へ進んでよい
  • 登録したがメール確認（verify）が済んでいない人：受信箱を確認し、確認メール内のリンクを開く
  • まだ登録していない人：github.com/signup から新規登録する。教員が個別にサポートする
早く終わった人へ: 全員がそろうのを待つ必要はありません。ログインできることを確認できたら、そのまま1限後半のリポジトリのフォーク作業を先に始めてください。
1限 後半 約50分

授業用リポジトリをフォークし、Codespacesを自分で起動する

今日は一斉ガイド形式で進める（参考）

教員の画面を見ながら全員で同じ手順を一斉に進める。詰まったら手を挙げてその場で確認する。

リポジトリをフォークする

  • 教員が案内する授業用リポジトリを開き、右上の「Fork」ボタンから自分のアカウントへフォークする（公式: Fork a repo）
  • なぜ各自フォークするのか：このリポジトリは第6回にGoogle AI Studioから読み込み直すため、自分がアクセス権を持つコピーが必要になる

Codespacesを起動する

  • フォークした自分のリポジトリを開き、「Code」ボタン→「Codespaces」→「Create codespace on main」（公式: Creating a codespace for a repository）
  • ブラウザ上にVS Codeの画面が立ち上がることを確認する
  • 左のファイルツリー、真ん中のエディタ、下のターミナル——第2回の教員デモで見た画面と同じ位置構成になっていることを確認する
使い終わったら停止する習慣を: GitHub Codespacesの無料枠には月ごとの上限があります（プランによって条件が異なるため、都度公式情報で確認してください）。今日の授業が終わったら、Codespacesの一覧画面から今日使った環境を停止しておきましょう。次回は「Create codespace」で新規作成せず、同じ環境を再開（resume）します——ファイルシステムやインストール済みのツールはそのまま残ります（公式: Understanding the codespace lifecycle「Any saved changes in your codespace will still be available when you next start it.」）。
休憩 10分
2限 前半 約50分

agyをインストールして認証する

なぜCodespacesの中に入れるのか

  • 第1回・第2回の教員デモで見たAntigravity CLI（agy）を、今日は自分のCodespaces上で動かす
  • agyはターミナルで自然言語の指示を受け取り、実際にファイルへ変更を加える——AIエージェントとしての動き方をこれから体感していく

インストールする

Codespacesのターミナルに、次のコマンドをそのまま貼り付けてEnter（公式: Antigravity CLI — Installation & auth）。

curl -fsSL https://antigravity.google/cli/install.sh | bash

認証する

  • インストール後agyを実行すると認証が求められる
  • 表示される認可URLをブラウザで開き、Googleアカウントでサインインしてコードを貼り付ける
  • ヘッダーにメールアドレスが表示されれば準備完了
うまくいかない時: 認証画面が開かない・コマンドがエラーになる場合は、ターミナルでもう一度agyと入力してみてください。それでも動かない場合は手を挙げて教員に相談してください。
2限 後半 約30分

agyに最初の仕事を頼む

自己紹介させる

  • 自然言語で話しかけてみる。例: あなたが何をできるか、自己紹介してください
  • 「すごい」「怖い」「よく分からない」——率直な感想でよいので、自分の言葉で言語化してみる

小さなファイルを1つ作らせる

  • 例: profile.md というファイルを作って、あなたの名前と今日感じたことを書いてください
  • 左のファイルツリーにprofile.mdが現れることを自分の目で確認する
  • ファイルを開き、agyが書いた中身を実際に読んでみる——AIエージェントが本当にファイルへ変更を加えたことを体感する
まとめ 約10分

次回予告＆今日の振り返り

  • 次回（第4回）：agyと一緒につくる①——今日フォークしたリポジトリに、agyへの自然言語の指示で小さな機能を1つ追加する
  • 今日フォークしたリポジトリは、第6回にGoogle AI Studio Build modeから読み込み直します。名前を覚えておいてください
  • 「GitHub・Codespaces・agyについて分かったこと・まだよく分からないこと」を一言メモして退出

課題・次回までにやること

必須
今日フォークしたリポジトリ名を控えておく

第6回にGoogle AI Studio Build modeから同じリポジトリを読み込み直すため。Codespaceは停止したままでよい（次回resumeで再開する）。

推奨
agyに他の指示も試してみる

時間のあるときに、profile.mdの内容を書き換えさせる等、簡単な指示を追加で試しておくと次回スムーズです。
