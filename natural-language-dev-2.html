自然言語開発 II

後期 木曜 3・4限 IT・情報処理専攻(システム) 3年次

担当教員

本田 康志

非常勤講師 / ヤススシステム代表

3年次のみなさん、前期はお疲れ様でした。進級制作を通じて、コンテキストエンジニアリング・SDD・TDD・ハーネスエンジニアリングを一通り体験し、AIエージェント（Antigravity CLI）の威力を実感してもらえたと思います。後期はさらに一歩進み、Claude Code／Codex CLI／Antigravity CLIといった複数の生成AIエージェントを、各自の契約状況に応じて使い分けながら本格的に動かしていきます。舞台となるのは、無料プランで始められるクラウド（Neon・Cloudflare Workers／D1）です。本物のクラウドサービスと連携するアプリを作りながら、ハーネスエンジニアリングをより本格的に体験します。個人情報を扱えるレベルの安全設計があることも学びながら、進級制作をクラウドの力とAIエージェントとの協働でさらに育てていきましょう。

授業概要

  • 本科目の一番の軸は、複数のコーディングAIエージェント（Claude Code／Codex CLI／Antigravity CLI）と、各自の契約状況に応じて柔軟に協働する経験を積むことです。特定のAIエージェントを使いこなすことがゴールではなく、自分の状況に合ったAIエージェントとクラウド開発を進める経験そのものを大切にします。前期に育てたAIエージェント活用の力を土台に、後期は無料プランのクラウドサービス（Neon・Cloudflare Workers／D1）（および契約状況に応じて対象者はAWS）と組み合わせ、クラウドネイティブな開発を実践します。
  • クラウドは、無料プランで始められるNeon（Postgres）とCloudflare Workers／D1で学びます。Cloudflareの無料プランには1日あたりの使用量の上限があり、上限を超えると処理が止まります（Cloudflare公式。D1は2026-09-01から、無料枠の上限を超えるとクエリが失敗）。当初はGoogle Cloud（Firebase・Cloud Run・Firestore）を使う計画でしたが、第9回から使わない方針に変更しました（2026-11-11）。
  • 本科目はClaude Code／Codex CLI／Antigravity CLIという3つの生成AIエージェントCLIを、各自の契約状況に応じて使い分ける複合運用とします。Claude Codeを使いたい学生は、既存のClaude契約か、後述のAmazon Bedrock経由の接続を用意します。既にClaude契約（Claude Pro等）がある学生はそのままClaude Codeを使います。ChatGPTアカウントがある学生はCodex CLIをまずFreeプランで試し、公式の機能比較表はPlus（$20/月〜）以上のプランでの利用のみ明記されているため、動作しない場合はPlus以上への加入を検討します（OpenAI公式）。いずれの契約もない、またはしたくない学生はAntigravity CLI（agy）——Googleアカウントでの認証のみで追加契約不要——を使います。
  • Claude Codeを使いたいが個人でClaude契約がない学生は、Amazon Bedrock経由で接続する選択肢があります（第3回でAWSアカウントを作れる学生のみ対象）。AWSの新規登録者向けクレジット（最大$200・6ヶ月間）はBedrockにも使えますが、AWS公式規約では新規特典は1人（1エンティティ）につき1アカウントまでとされ、既存のAWSアカウント保有者は対象外です。クレジットカード番号が判定に使われるかどうかを含め、具体的な判定基準はAWS公式では非公開のため、本人が過去にAWSアカウントを持っていたかどうかで対象可否が変わりうることを理解しておきます。対象外の場合、登録初日から実費（従量課金、金額は利用状況により変動）が発生します。過去の利用有無に心当たりがなく不安な場合は、事前に担当教員に相談してください。Bedrockのモデルアクセスは既定で有効になっており、Anthropicモデルは初回のみ利用目的（Use case）フォームの送信が必要ですが、送信後は即座に使えるようになります（旧来の「モデルごとに手動でリクエストして承認を待つ」手順は現在は不要、Amazon Bedrock公式）。
  • Cloudflareの操作はWrangler（Cloudflare公式のCLI）、Neonの操作はNeon CLI、GitHubの操作はgh CLIを、使用中のAIエージェント（Claude Code／Codex CLI／Antigravity CLIのいずれか）から呼び出して進める形を標準パターンとします。
  • Playwright MCP（ブラウザ操作）やclasp（Command Line Apps Script Projects、Google Apps Scriptのローカル管理）にも触れ、CLIとMCPを通じてAIエージェントが扱える範囲の広さ・パワフルさを体感します。
  • クラウドAIサービスのデータガバナンス（入力データがモデルの学習に使われない設計等）を学び、「個人情報を扱えるレベルの安全設計」がどのように成り立っているかを理解します。
  • Cloudflareの使用量と無料枠の上限の確認や、AWSのコスト管理機能を使って、サービス単位での使用量・コスト状況を確認する習慣を身につけます。Cloudflareの無料プランは上限を超えると処理が止まるのに対し、AWSの既定のアラート機能は通知のみで支出を自動的に止めるものではないことを対比して理解します（AWSには閾値超過時にIAMポリシー適用等で自動的に利用を制限できるBudgets Actionsという追加設定機能もありますが、既定では無効で本授業では扱いません）。個々のプロンプト単位の精密な課金確認は本授業の範囲外とし、まずはサービス単位でのコスト意識を持つことを目標とします。
  • 引き続き「責任あるコード」をテーマとし、クラウド環境でのAI活用における検証・品質管理の重要性を学びます。

到達目標

知識・理解

  1. Cloudflareの無料プラン（Workers・D1）の使用量の上限と、上限を超えると処理が止まる仕組みを理解し、公開したURLは誰でもアクセスできることを踏まえて、保存してよいデータを判断できる。
  2. Claude Code／Codex CLI／Antigravity CLIそれぞれの契約要件（Claude契約またはAWS Bedrock、ChatGPTアカウント——まずFreeで試し必要ならPlus以上——、Googleアカウントのみ）の違いを理解し、自分がどれを使うか判断できる。AWSアカウント登録・Bedrockを選ぶ場合は、過去のアカウント履歴によって新規特典の可否が変わりうるリスクも理解している。
  3. Claude・GPT・Geminiなど複数のAIモデルの違いと、それぞれの特性を自分の言葉で説明できる。
  4. クラウドAIサービスにおけるデータガバナンス（学習への非利用等）の基本的な考え方を理解している。
  5. Cloudflare Workers（コードを動かす場所）・D1（データを置く場所）・Neonがそれぞれ何をするサービスかを説明できる。
  6. 使用中のAIエージェントがCLI（Wrangler・gh等）やMCP（Playwright MCP等）を通じて外部ツールを操作する仕組みを理解している。

思考・判断

  1. 無料プランの使用量の範囲でどこまで開発を進めるか、コストを意識して判断できる。
  2. 個人情報や機密情報をAIに入力してよい場面とそうでない場面を、データガバナンスの観点から判断できる。
  3. 自分の進級制作のどこにクラウド機能を統合すると価値が生まれるかを考えられる。

スキル・表現

  1. Cloudflareアカウントを作成できる。契約状況に応じて、既存のClaude契約でClaude Codeにログインする、ChatGPTアカウントでCodex CLIにログインする、AWSアカウントを作成してBedrockを有効化する、またはAntigravity CLIをGoogleアカウントで認証するのいずれかでAIエージェントを使える状態にできる。
  2. Claude Code／Codex CLI／Antigravity CLIのいずれかをセットアップし、実際に動かせる。
  3. Cloudflare Workers・D1とNeonの基本操作を行い、進級制作にクラウド機能を統合できる。
  4. Cloudflareのダッシュボードで使用量と無料枠の上限を確認し、AWSの予算アラート等のコスト管理機能でコスト状況を確認し、必要に応じて設定を調整できる。
  5. 使用中のAIエージェントからWrangler・gh CLIを呼び出して基本的な操作を行い、Playwright MCPで自分のアプリの動作をAIエージェントに確認させられる。

関心・意欲・態度

  1. お金や個人情報が関わりうるクラウド環境に対して、責任を持って慎重に取り組む姿勢を持つ。
  2. 技術の急速な変化（サービス名称の変更等）に対して、公式情報を確認しながら柔軟に対応する姿勢を持つ。
  3. 前期からの学びを土台に、新しい環境に臆せず挑戦する姿勢を持つ。

授業計画（全16回）

週 テーマ 主な内容・活動
1前期振り返り＆後期オリエンテーション前期に取り組んだ進級制作のBefore/After比較、AIエージェント（Antigravity CLI）活用の学びを振り返る。後期のゴール——Google Cloud実アカウントを使ったクラウドネイティブ開発——を共有し、全16回の流れを俯瞰する。本科目はClaude Code／Codex CLI／Antigravity CLIを各自の契約状況に応じて使い分ける複合運用とする方針も確認する。
2Google Cloudアカウントを作ろう個人のクレジットカードでGoogle Cloudに新規登録し、$300分・90日間の無料クレジット（Welcome credit）を確認する。トライアル終了時は自動課金ではなく自動的にアカウントがクローズされる仕組みで、90日という期限が全16回の授業期間より短いことも共有する。Google Cloud側では有料アカウントへの切り替えは行わず、第13回頃までのトライアル期間内でFirebase・Cloud Run・Firestoreの実操作を終える計画であることを伝えておく。
3AIエージェントを選ぼう（AWS登録は対象者のみ）各自の契約状況（Claude契約・ChatGPTアカウントの有無）を確認し、使うAIエージェントを決める。Claude Codeを個人契約なしで使いたい学生のみ、個人のクレジットカードでAWSに新規登録する（登録時「Free Plan」を選択、新規特典が最大$200・6ヶ月間だが1人1アカウントまで・カード番号が判定に使われるかは非公開であることを共有）。Codex CLIを使う学生はまずChatGPT Freeアカウントで動作を試す（公式の機能比較表はPlus（$20/月〜）以上のプランのみを対象としており、Freeで動作しない場合はPlus以上への加入を検討する）。AWS登録もPlus加入もしたくない学生はAntigravity CLI（agy）——Googleアカウントでの認証のみで追加契約不要——を使う。AWS登録した学生は、Amazon BedrockのモデルカタログでAnthropicのモデルを選び、初回のみ利用目的（Use case）フォームを送信する（個人開発者は学校のリポジトリURLやポートフォリオURL等で代用可能。送信後は即座にアクセスできるようになる——モデルアクセス自体は既定で有効になっており、旧来の「モデルごとに手動でリクエストして承認を待つ」手順は現在は不要、Amazon Bedrock公式）。Bedrockを実際に呼び出す前にAWSの予算アラート（Budgets）を低めのしきい値で設定しておく（通知の反映には8〜12時間程度のタイムラグあり、AWS公式）。Claude Codeの接続時は、既定で優先される上位モデル（Opus）ではなくSonnetをウィザードのモデル固定（pin）ステップで選ぶ——Opusは1トークンあたりの料金がSonnetより高いため（Claude Code on Amazon Bedrock公式）。あわせて、AIエージェントがCLI（gcloud・gh）やMCP（Playwright MCPでのブラウザ操作、claspでのGoogle Apps Script管理）を通じて外部ツールを操作できる幅の広さを、教員のデモで体感する。
4対戦ゲームの仕組みを読み解こう前回、クラス内1人の学生がagy／Codex CLIへの「対戦ゲーム機能を追加して」という指示だけで、GitHub Codespaces上に6人同時対戦のリアルタイム対戦ゲームを実装し、学校WiFi経由でみんなが参加した体験を教材に、図解を通じてクラス全体でその裏側の技術を読み解く。実装した本人のCodespaceが全員の操作を受け取って配信する「サーバー」の役割、パスコードで対戦グループを区別する「ルーム」の仕組み、常時接続したまま双方向にデータをやり取りするWebSocketという技術に、実装した本人への質問と図解を通じて触れる。続けて、Codespacesのポート転送を「パブリック」に設定すると、実は学校WiFiの中かどうかに関係なくインターネット上の誰からでも認証なしにアクセスできる状態になっていたという事実を公式ドキュメントで確認し（NATの仕組みはCodespacesがその壁を越えている背景として軽く触れる）、そこに潜む脆弱性とセオリーとしての多層防御（Defense in Depth）を、OWASP等の一次情報をもとに理解する。本番で正しく公開するなら、意図したセキュリティ設計を組み込めるクラウドサービス（Cloud Run）に置くのが筋であることにも触れ、第7回Cloud Run（見るだけ）・第9回Cloudflare Workers／D1で学ぶ内容の伏線として位置づける。
5スコアを保存して守ろう：カード不要のNeonとセキュリティ前回の対戦ゲームのスコアを残すために、クレジットカード不要で始められる無料のクラウドDB Neon（Postgres）を、使用中のAIエージェントからCLIで作り、Node.jsの数行のスクリプトでスコアを保存・取得する。あわせて、AIエージェントに送られるデータの扱い（学習への利用・保存期間）を公式資料で確認し、接続文字列は「パスワード相当」の秘密であることを、隣の人に渡す体験を通じて実感する。最小権限（読み取り専用ロール）の考え方と、何を保存・入力してよい／よくないかも話し合う。
6自然言語でデータを残そう：カード不要のNeon実習前回までの対戦ゲームのスコアなど、データを永続化（Codespaceを止めても残す）する体験を、クレジットカード不要の無料クラウドDB Neon（Postgres）で行う。使用中のAIエージェントに頼んで、CLIでアカウントなしの一時プロジェクト（72時間）を作り、スコアを保存し、自然言語でDBに質問して、エージェントが書いたSQLを読んで確かめる。接続文字列は「パスワード相当」の秘密であることを.envと.gitignoreで守る基本として身につけ、読み取り専用ロール（最小権限）も体験する。
7話題のAI製ゲームを、自然言語で再現しよう2026年10月に話題のAI製ブラウザゲーム『80億分の1』（公開統計にもとづく人生シミュレーション。運営者がAIと一緒に制作と公式に記載）を、公式の授業用モードで遊び、仕組みを入力・状態・ルール・データ・出力・保存の6つの箱に分ける。そのアイデアだけを借りて、自分の題材を決め、仕様を1ページで書いて使用中のAIエージェントに渡し、動く最小版を作る（プログラム・文章・絵は写さない）。作り直したNeonに結果を残し、自然言語で集計してSQLを読む。最後に、ブラウザとDBの間にサーバーを置く理由と、その置き場所の一つであるCloud Runを、図と教員の説明で見る（学生のGoogle Cloud登録・実操作は行わない）。
8AIエージェントに効率よく働いてもらう、指示の4つの型同じAIエージェントでも、指示のしかたで結果と手間が変わる。使用中のAIエージェント（Claude Code／Codex CLI／Antigravity CLI）に効率よく働いてもらうための4つの型——①先に質問させる（実行前に選択肢で聞かせる。Claude CodeのAskUserQuestionなど）②計画だけ立てさせる（planモード）③道具で解決できるか聞く（CLIやMCP）④確かめ方を渡す（合否が出る確認と証拠）——を知り、第7回の題材で試して指示の型カードにまとめる。1限前半に、ここまでの学びの短い振り返りを行う。
9Cloudflare WorkersとD1に触れてみよう第7回で図だけ見た「ブラウザとDBの間のサーバー」を、Cloudflare Workers（コードを動かす場所）で実際に置く。Wrangler（CLI）でD1（SQLite系のデータベース）を作り、スコアを保存・取得するWorkerを使用中のAIエージェントと協働で作って、workers.devに公開する。無料プランの使用量の上限と、公開したURLは誰でもアクセスできることを確認する。
10進級制作にクラウド機能を統合①：設計進級制作のどこにクラウド機能（Cloudflare Workers／D1・Neon等）を統合するかを計画する。使用中のAIエージェントと協働でPRD・ADRを作成する。
11進級制作にクラウド機能を統合②：実装第10回の計画に基づき、使用中のAIエージェント（Claude Code／Codex CLI／Antigravity CLI）と協働で実装を進める。GitHubの操作（PR作成等）もgh CLIを使ってAIエージェントから行う。
12無料枠と課金を可視化しようCloudflareのダッシュボードで使用量と無料枠の上限を確認し、サービス横断でコスト状況を確認する習慣を身につける。Cloudflareの無料プランは上限を超えると処理が止まるが、AWSの既定のアラートは通知のみで、支出や課金を自動的に止めるものではないことを対比して理解する（AWSには自動制限機能Budgets Actionsもあるが既定では無効で本授業では扱わない）。AWS登録した学生（Claude Codeを個人契約なしで使う学生）は第3回から使ってきたAWSの予算アラートの履歴もあわせて振り返る（AWS登録した学生のクレジットは6ヶ月間のため、通常は学期末まで持続する見込み）。
13検証と改善実装した機能のテスト・動作確認。Playwright MCPを使用中のAIエージェントに追加し、自分が作ったWebアプリをAIエージェントに実際に操作・確認させる。Cloudflareの無料枠の上限に近づいたときの動作（処理が止まる）も確かめる。
14責任あるAI開発（クラウド版）クラウド環境でのAI活用における検証・品質管理・データガバナンスの観点から、自分の実装を見直す。
15最終仕上げ進級制作の最終調整、ドキュメント整備。
16🎤 最終発表会＆総括クラウド機能を統合した進級制作の成果発表。前期・後期を通じた技術の進化を振り返る。

  • 復習: 授業で行った設定・気づいたことをリポジトリのdocsやADRに記録しましょう。

評価方法・基準

クラウド環境を責任を持って扱いながら、実際に手を動かして進級制作にクラウド機能を統合できたかを重視します。

25%クラウド環境構築・活用の実践 — Cloudflareアカウント作成からAIエージェント連携、Workers／D1・Neonの活用まで、実際に手を動かした度合い。
25%実装・コードの品質 — クラウド機能統合の動作、可読性、保守性。
20%セキュリティ・コスト意識 — データガバナンスの理解、Cloudflareの使用量と無料枠の上限の確認、AWSの予算アラートによるコスト管理の実践。
15%開発プロセス — GitHub Flowの実践、AIエージェント（Claude Code／Codex CLI／Antigravity CLI）との協働プロセス。
15%発表・責任あるAI開発の実践 — 最終発表への取り組み、検証姿勢。

その他（履修上の注意点）

  • Cloudflareは無料プランで使います（Workers Free: 1日100,000リクエスト。D1 Free: 読み取り500万行／日・書き込み10万行／日。毎日UTC 0時＝日本時間9時にリセット。いずれもCloudflare公式、確認日2026-11-11）。上限を超えると処理が止まります。登録時にクレジットカードを求められるかは公式に明記が見つからないため、授業前に教員が登録画面で確認します。ログインできない場合に備え、一時アカウントにデプロイする方法（wrangler deploy --temporary、60分以内に引き継がないと削除）も用意します。公開したworkers.devのURLは誰でもアクセスできるため、個人情報は入れません。
  • 本科目はClaude Code／Codex CLI／Antigravity CLIの複合運用です。Codex CLIを使う場合はまずChatGPT Freeアカウントで動作を試してください（公式の機能比較表はPlus（$20/月〜）以上のプランのみを対象としており、Freeで動作しない場合はPlus以上への加入を検討します）。Antigravity CLI（agy）はGoogleアカウントでの認証のみで追加契約は不要ですが、無償枠には週次のレート制限があり、上限に達すると翌週まで待つか有料プランへのアップグレードが必要になる場合があります（Google公式）。いずれの契約もない、またはPlus加入をしたくない学生はAntigravity CLIで進めてください。
  • Claude Codeを個人契約なしで使いたい学生のみ、AWSの利用に個人のクレジットカードが必要です。登録時は無料クレジットの対象となるFree Planを選びます（Paid Planとの選択画面が表示されます）。新規登録者には最大$200・6ヶ月間のクレジットが提供されますが、AWS公式規約では新規特典は1人（1エンティティ）につき1アカウントまでとされ、既存のAWSアカウント保有者は対象外です。クレジットカード番号が判定に使われるかどうかを含め、具体的な判定基準はAWS公式では非公開のため、対象になるかどうかは登録してみないと分かりません。対象外の場合、Claude Code経由の利用は登録初日から実費（従量課金、金額は利用状況により変動）が発生します。過去のAWS利用状況に不安がある場合は、登録前に担当教員に相談してください。
  • AWSのFree Planアカウントは、公式規約上評価目的での利用に限られ、機微なデータの処理には使わないこととされています。進級制作にAWS Bedrock経由でClaude Codeを接続する際も、実在する個人情報等の機微なデータは入力しない運用を徹底してください（第5回のデータガバナンス学習ともあわせて確認します）。
  • claspはGoogle公式リポジトリ（github.com/google/clasp）で開発されていますが、READMEに「公式にサポートされる製品ではない（not an officially supported Google product）」と明記されているツールです。体験・紹介の位置づけで扱います。
  • 実際に課金が発生しうる環境を扱うため、不安な点があれば早めに担当教員に相談してください。
  • 体調やメンタル面で不安がある場合は、無理せず担当教員または学校の相談窓口に相談してください。
