第9回デモ：進級制作で Map を使う

Week 9 動く MVP

授業の到達点（Leaflet 1.9.4 + OpenStreetMap タイル + Open-Meteo Geocoding API + Open-Meteo Forecast API）をそのまま 1 ファイル HTML に集約した最小実装。 入力欄に地名を入れて「天気を見る」を押すと、ジオコーディング API で緯度経度を取得し、Forecast API で現在の天気を popup に表示します。 API キー不要・非商用無料・初期表示は天王寺（34.6435, 135.5132）。

Stack: L.map / L.tileLayer / L.marker / L.popup（Leaflet 1.9.4）· OpenStreetMap タイル（attribution 表示） · Open-Meteo Geocoding API（name / count=1 / language=ja） · Open-Meteo Forecast API（current=temperature_2m,weather_code） · WMO weather_code 日本語辞書（96 = 雷雨と雹（少量）/ 99 = 雷雨と雹（多量）等）
