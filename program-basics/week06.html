テーマ

  • console.log で値を出力し、ブラウザの開発者ツールの Console で確認できる

1限 前半 約40分

HTML/CSS と JavaScript の役割の違いを理解する

前回までの振り返り（10分）

  • 第1〜5回で書いてきたのは HTML（文書の構造）と CSS（見た目・レイアウト）
  • 第5回ではメディアクエリでスマホ表示を整えた——でも、ページを開いた時点で見た目は決まっていて、その後は何も変わらない状態だった
  • 今日からは JavaScript で「ページを開いた後にも動く」要素を作る

「3つの言葉」の役割分担（15分）

  • 3つの言語は役割が違う——MDN「JavaScript とは」の整理:
    • HTML: ページの構造を組み立てる（見出し・段落・リスト・画像）
    • CSS: 構造にスタイルを当てる（色・余白・レイアウト）
    • JavaScript: ページに動的な動きを加える（クリックで反応、内容を書き換える、計算する）
  • たとえ話: HTMLが「家の骨組み」、CSSが「壁紙と家具」、JavaScript が「電気とスイッチ」
  • 3つは同じ HTML ファイル上に共存できる——今日はその同居の最初の一歩

<script> タグを書いてみる（15分）

  • 第5回までの index.html を開く（消した人は新規でも可）
  • </body> の直前に <script> ブロックを追加: 
    <script>
  console.log("はじめての JavaScript");
</script>
</body>
  • ページを表示する手順（第1回と同じ、要点だけおさらい）:
    1. Codespaces 下部のターミナル（無ければ Ctrl + ` または「表示」→「ターミナル」）に python3 -m http.server 8000 をそのまま貼り付けて Enter——Python 標準ライブラリの簡易 HTTP サーバーがポート 8000 でカレントディレクトリを公開する（8000 はデフォルトポート番号と同じだが、明示しておくと事故が減る）
    2. Codespaces はターミナル出力に含まれる localhost URL を検知して自動でポート転送する仕組み（公式: Forwarding ports in your codespace）。起動と同時に右下にトーストが出れば、それをクリックでもよい
    3. トーストを閉じてしまった・出なかった時は、画面下部の 「ポート」タブ を開き、8000 番 の行を探す。その行で 「エディターでプレビュー」（画面アイコン）を選ぶとエディタ内に Simple Browser が開く。隣の「ブラウザーで開く」（地球儀アイコン）は外部ブラウザを起動するため、学校環境では Simple Browser のほうを選ぶ
    4. ページが表示されたら成功。ファイルを保存しても自動では反映されないので、Simple Browser の更新ボタンで再読み込みする
    詳しい初回手順や詰まった時のフォールバックは 第1回 を参照
  • ページ自体は何も変わらない——動きは画面の裏側にいる。次のステップで取り出す
なぜ </body> の直前か: JavaScript は HTML が読み込まれてから実行するほうが安全な場面が多いので、まずはこの位置を癖にします（MDN「HTML <script> スクリプト要素」でも紹介される基本パターン）。<head> 内に書く方法もありますが、それは後の回で扱います。

Console を開き、変数とデータ型を手で書く

開発者ツールの Console を開く（10分）

  • Simple Browser で表示中のページ、または別タブで開いた公開 URL で F12 または右クリック → 検証
  • 上のタブから 「Console」 を選ぶ（第5回の DevTools と同じ画面、別のタブ）
  • さっき書いた console.log("はじめての JavaScript") の出力がここに表示されているはず
  • これが「JavaScript からの声」を聞く場所——以降ずっと使う

変数を手で宣言する（15分）

  • <script> ブロックの中身を書き換える: 
    <script>
  let name = "あなたの名前";
  const year = 2026;
  console.log(name);
  console.log(year);
</script>
  • let: あとから変えてよい値を入れる箱（変数）
  • const: あとから変えない値を入れる箱（定数）
  • 保存 → Simple Browser を更新 → Console を確認:
    • 「あなたの名前」と 2026 が表示されたら成功
    • 文字には引用符（" または '）が付き、数字には付かない——これがデータ型の違いの最初のヒント
  • MDN「必要な情報を保管する — 変数」では「箱に名前を付けて中身を出し入れする」というイメージで説明されている。最初はそれで十分

3つの基本データ型を見分ける（15分）

  • JavaScript で最初に出会うデータ型は3つ（MDN「文法とデータ型」より）: 
    let myString  = "こんにちは";    // 文字列（String）
let myNumber  = 42;              // 数値（Number）
let myBool    = true;            // 真偽値（Boolean）

console.log(typeof myString);   // "string"
console.log(typeof myNumber);   // "number"
console.log(typeof myBool);     // "boolean"
  • typeof はその値が「どの型か」を教えてくれる演算子——今は呪文として使ってOK
  • よくある間違い: "42"（引用符あり）と 42（引用符なし）は別物。前者は文字列、後者は数値。Console で "42" + 1 と 42 + 1 を試して挙動の違いを観察

変数を組み合わせて文章を作る（10分）

  • テンプレートリテラル（バッククォート `）を使うと、文字列の中に変数を埋め込める: 
    let myName = "山田 太郎";
let myAge  = 20;
console.log(`私の名前は ${myName} で、${myAge} 歳です。`);
  • ${ 変数名 } の部分が、値に置き換わる
  • 自分の自己紹介文を1つ、変数を使って組み立ててみる

配列と Math.random でおみくじのロジックを組む

配列で「候補のリスト」を作る（10分）

  • 「大吉・中吉・小吉・末吉・凶」のように、並びの中から1つを選ぶ用途には配列を使う: 
    const fortunes = ["大吉", "中吉", "小吉", "末吉", "凶"];
console.log(fortunes);       // 全部
console.log(fortunes[0]);    // "大吉"
console.log(fortunes[2]);    // "小吉"
  • 配列の番号は 0 から始まる——これが最初のつまずきポイント
  • fortunes.length で配列の長さ（要素数）を取得できる

Math.random でランダムな数を作る（15分）

  • Math.random() は 0 以上 1 未満の乱数を返す関数（MDN「Math.random()」） 
    console.log(Math.random());    // 例: 0.7234...
console.log(Math.random());    // 例: 0.1029...
  • これを配列の番号として使うには「0以上、配列の長さ未満」の整数に変換する必要がある: 
    const fortunes = ["大吉", "中吉", "小吉", "末吉", "凶"];
const index = Math.floor(Math.random() * fortunes.length);
console.log(index);            // 0〜4 のどれか
console.log(fortunes[index]);  // ランダムに選ばれた1つ
  • Math.floor は小数点以下を切り捨てて整数にする関数。Math.random() * 5 は 0以上5未満、それを切り捨てると 0〜4 になり、配列の番号と一致
  • Console で何度か実行して、毎回違う結果が出ることを観察

おみくじを HTML 上に表示する（25分）

  • これまで Console にしか出ていなかった結果を、いよいよページ本体に表示する
  • index.html の <body> 内に表示用のタグを追加: 
    <h2>今日の運勢</h2>
<p id="fortune">ここに結果が出ます</p>
  • <script> の中身を書き換える: 
    const fortunes = ["大吉", "中吉", "小吉", "末吉", "凶"];
const index    = Math.floor(Math.random() * fortunes.length);
const result   = fortunes[index];

console.log(result);

// HTML の id="fortune" の要素を取り出して中身を書き換える
document.getElementById("fortune").textContent = result;
  • document.getElementById("fortune") は「id="fortune" の HTML 要素を JavaScript の手元に引き寄せる」呪文（詳しくは第11回 DOM 操作で扱う、今日は使い方だけ）
  • 保存 → Simple Browser を更新 → 毎回違う結果が出る
  • 第4回でやった commit & push を思い出して、自分のリポジトリに保存しておく
「動いた」で止めない: おみくじが動いたら、自分の言葉で 「配列の何番目が選ばれて、それを HTML に書き込んでいる」 と説明してみてください。説明できれば、来週の「条件分岐＆バグ修正ワーク②」がぐっと楽になります。

おみくじを自分らしくカスタマイズし、コメントで言語化する

選択肢を自分仕様にする（10分）

  • fortunes 配列の中身を、自分が普段使う言葉に書き換える（例: 「最高」「ぼちぼち」「ちょっと注意」など）
  • 項目数を 3個・5個・7個と変えて、それぞれおみくじが正しく動くか確認——fortunes.length を使っているので、配列の長さに自動で対応するはず
  • もし動かない時は Console を確認:「index が想定外の値になっていないか」「fortune の id 名がタイプミスしていないか」

コメントで「自分の言葉」を残す（15分）

  • JavaScript のコメントは // 一行コメント または /* 複数行 */: 
    // おみくじの候補リスト（順番に意味はない）
const fortunes = ["大吉", "中吉", "小吉", "末吉", "凶"];

// 0以上 配列長未満 の整数をランダムに作る
const index = Math.floor(Math.random() * fortunes.length);
  • 「なぜこう書いたか」を自分の言葉で残す——「何をしているか」だけならコードが語ってくれる
  • 来週この行を見たときの自分が、コメント無しで読めるか想像しながら書く
