シラバス一覧 / プログラム基礎 I / 第14回

自由制作＆振り返り

Week 14 火曜 1・2限
テーマ
前期最終回。前期に学んだHTML/CSS/JavaScriptを自由に組み合わせて作品を制作する。第13回とは逆に、今日はAIを使ってよい——何を手で書き、何をAIに任せるかは自分でルールを決める。完成した作品をGitHub Pagesに公開し、前期の学びを記録形式で自己振り返りする（発表なし）。後期への接続も行う
キーワード
自由制作 / 自分のAI利用ルール / 最終作品の公開 / 記録形式の自己振り返り（発表なし） / 後期への接続
必要な準備
第4・8・12回で公開済みの3作品・第13回の NOTES.md「デバッグ集中回の記録」・Codespaces が起動できる状態

この回のゴール

  • これまで学んだ技術を自由に組み合わせて、自分の作りたいものを形にできる
  • 「何を手で書き、何をAIに任せるか」を自分の言葉で決められる
  • 最終作品を GitHub Pages に公開できる
  • 前期の学びを記録形式で自己振り返りできる（発表を目的としない）

大事な前提（毎回投影しておく）

今日は発表会ではない: 最終作品は GitHub Pages に公開するが、クラスの前で発表する時間は設けない。前期を通じて大切にしてきた「自分の手で動くものを作る」体験の総仕上げとして、自分のペースで作り、自分の言葉で振り返ることを最優先にする。

授業の流れ

2コマ連続（90分 + 90分 = 計180分）。途中休憩あり。

1限 前半 約40分

前期を振り返る → 今日作るものを決める

前期の歩みを振り返る（10分）

  • 第4・8・12回で公開した3作品（プロフィールサイト・小ゲーム・クリックゲーム）と、第13回のデバッグ集中回を順に思い出す
  • 講師から、今日が前期最終回であることを共有

自分のAI利用ルールを決める（10分）

  • 「何を手で書き、何をAIに任せるか」を NOTES.md に1〜3行で宣言する。第13回でAIなしを経験したからこそ、今日は自分の判断で使い分けを選べる

今日作るものを決める（20分）

  • 作るものは自由——既存3作品のどれかを改良してもよいし、新しく作ってもよい
  • テーマ例: 3作品を1つのサイトにまとめる / 第12回で直せなかったバグを直しつつ機能を1つ追加する / 新しい小さな作品を1から作る
1限 後半 約50分

自由制作①（HTML/CSSで骨組みを作る）

制作（50分）

  • 決めたテーマに沿って HTML/CSS で骨組みを作る。第1〜5回で学んだタグ・レイアウトを自分で選んで組み合わせる
  • 迷ったら第4回（プロフィールサイト）・第8回（小ゲーム）の構造を見返してよい
休憩 10分
2限 前半 約50分

自由制作②（JavaScriptで動きを付ける）→ 公開する

制作（30分）

  • JavaScript で動きを付ける。第6〜12回で学んだ変数・条件分岐・繰り返し・配列・関数・DOM操作のうち、自分の作品に必要なものを選んで使う

commit & push で公開（20分）

  • 第4・8・12回と同じ手順（ソース管理タブ→コミット→Sync Changes）で GitHub Pages に公開する
  • 公開URLをブラウザの別タブで開き、動作確認する
2限 後半 約30分

前期の自己振り返り

振り返りを書く（25分）

  • NOTES.md に「前期の振り返り」という見出しを作り、次の3点を記録する: ①前期14回を通じて学んだこと・②一番成長を感じたこと・③後期にやってみたいこと
  • 発表は目的としない。うまくいかなかったことも含めて、率直に書く

4作品を並べて眺める（5分）

  • プロフィールサイト・小ゲーム・クリックゲーム・今日の最終作品、4つの公開URLを見比べ、一番成長を感じる部分を1つ選んで NOTES.md に書き添える
まとめ 約10分

前期全体の振り返りと後期への接続

  • 前期最終回であることを改めて共有し、第1回からの歩みをねぎらう
  • 今日のキーワード 「自由制作」「自分のAI利用ルール」「最終作品の公開」「記録形式の自己振り返り」「後期への接続」を口に出して言えるか確認して退出
  • 後期も引き続き4つの公開作品を育てていけることを伝える

課題・次回までにやること

必須
最終作品を GitHub Pages に公開し、NOTES.md に「前期の振り返り」を記録する

授業内で公開が間に合わなかった人は家で完成させる。振り返りの3点（学んだこと・成長・後期への希望）は必ず書き切る。

推奨
4つの公開作品を家族・友人に見せる

前期の集大成として、率直な感想をもらっておく。後期の制作のヒントになることがある。
