CSS発展：レイアウトを整える

Week 6 火曜 1・2限
テーマ
CSS Grid/Flexboxで、ゲーム画面や商品一覧など複雑なレイアウトを組む。第5回の企画シートに書いた画面構成を、実際に画面として組んでみる
キーワード
Flexbox / display: flex / justify-content / align-items / flex-wrap / Grid / grid-template-columns / repeat / fr / gap
必要な準備

この回のゴール

  • Flexboxで要素を横一列に並べ、justify-contentとalign-itemsで並べ方を変えられる
  • Gridで要素を格子状に並べ、repeatで列の数を変えられる
  • 「一列に並べるならFlexbox、格子に並べるならGrid」と、使い分けを自分の言葉で言える
  • 自分の作品の画面構成（plan.md）を、layout.htmlとして組み、commit・pushできる

何も指定しないと、縦に積まれることを確認する（10分）

display: flexで横一列に並べる（20分）

  • <style>の中、.cardの下に、次の1行を追加して保存・更新する： 
    .cards { display: flex; gap: 12px; }
  • 4枚のカードが横一列に並ぶ。カードの幅は中身の大きさになる
  • ここが最重要のポイント：display: flexは並べたいものの「親」（.cards）に書く。.card（子）には書かない。親に書くと、その直下の子が横に並ぶ
  • gapは、子と子のすき間。12pxを40pxに変えて、すき間が変わることを確かめて、元に戻す

Flexboxの並べ方を変え、スコアバーを作る

主軸の並べ方を変える：justify-content（15分）

  • .cardsの1行を次のように書き換え、値を順に変えて、カードの位置がどう変わるかを見る： 
    .cards { display: flex; gap: 12px; justify-content: space-between; }
  • 試す値は3つ：flex-start（左づめ。何も書かないときは、これと同じ動き）／center（中央）／space-between（両端に寄せて、間を均等に空ける）
  • justify-contentは主軸（横）の並べ方を決める

交差軸の並べ方を変える：align-items（10分）

  • .cardsに、高さとalign-itemsを足す： 
    .cards { display: flex; gap: 12px; height: 120px; align-items: center; }
  • 試す値は3つ：stretch（縦に伸びて高さをそろえる。何も書かないときは、これと同じ動き）／flex-start（上づめ）／center（縦の中央）
  • align-itemsは交差軸（縦）の並べ方を決める。justify-contentとalign-itemsは、横と縦の組で覚える
  • 確認ができたら、height: 120px;とalign-items: center;を消して、前の状態に戻す

入りきらないときに折り返す：flex-wrap（10分）

  • </body>の直前に、タグが7つ並ぶ部分を追加し、<style>に2つのルールを足す

      <h2>タグを並べる</h2>
  <div class="tags">
    <span class="tag">マグ</span>
    <span class="tag">ノート</span>
    <span class="tag">ペン</span>
    <span class="tag">ふせん</span>
    <span class="tag">ハサミ</span>
    <span class="tag">定規</span>
    <span class="tag">消しゴム</span>
  </div>
        .tags { display: flex; gap: 8px; }
    .tag { padding: 4px 12px; background: #fde8d0; border-radius: 16px; }
  • Simple Browserの幅を狭くしたり、タグを増やしたりして、1行に入りきらない状態にする。初期のままだと、タグが1行に押し込まれて窮屈になる
  • .tagsにflex-wrap: wrap;を足すと、入りきらない分が次の行へ折り返すことを確認する

演習：画面の「帯」（スコアバー）を作る（15分）

  • ゲームのスコア表示や、ECサイトの上の帯（店名とカートの点数）のように、左と右に離して置く帯を作る。</body>の直前に、次のHTMLを追加する：

    • 縦方向は中央にそろう（padding: 12px 16px;と、背景色background: #3d5a73;・文字色color: white;を足すと帯らしくなる）

Gridで格子状に並べ、FlexboxとGridを使い分ける

Flexboxでは足りない場面を知る（10分）

  • 第5回の画面構成を思い出す——もぐらたたきの6つの穴（3列×2行）、雑貨店の商品カードの並び。これは「一列」ではなく、縦にも横にも並ぶ格子
  • Flexboxは基本的に一列（主軸の向き）に並べる道具。折り返しを使えば複数行にはできるが、各行が別々に詰められて行をまたいだ列は揃わない（揃えるには幅の計算が必要）
  • 格子に並べるために作られたのがGrid。今から、同じlayout-demo.htmlに追加して試す

Gridの基本：grid-template-columnsとrepeat（20分）

  • </body>の直前に6つの穴を追加し、<style>にGridのルールを足す

      <h2>穴を格子に並べる</h2>
  <div class="holes">
    <div class="hole"></div>
    <div class="hole"></div>
    <div class="hole"></div>
    <div class="hole"></div>
    <div class="hole"></div>
    <div class="hole"></div>
  </div>
        .holes { display: grid; grid-template-columns: repeat(3, 1fr); gap: 12px; }
    .hole { aspect-ratio: 1 / 1; border-radius: 50%; background: #ddd; }
  • 6つの円が3列×2行の格子に並ぶ。Flexboxと同じく、display: gridは親（.holes）に書く
  • grid-template-columns: repeat(3, 1fr)——同じ幅の列を3本作る、という意味
    • repeat(3, 1fr)は、1fr 1fr 1frと同じ意味の短い書き方
    • frは「余っている幅を何等分したうちの何個分か」を表す単位。1frの3列は、幅を3等分した列になる
  • 数字を変えて試す：repeat(3, 1fr)をrepeat(2, 1fr)やrepeat(6, 1fr)にすると、列の数が変わる。1fr 2fr 1frと書くと、真ん中の列だけ2倍の幅になる。確認できたらrepeat(3, 1fr)に戻す
  • 子が6個で3列なら、行は自動で2行になる。行の数は書かなくてよい（子の数に合わせて増える）

ECサイトの商品一覧：画面の幅に合わせて列の数を変える（10分）

  • 商品カードを並べる部分を追加する。ゲームを選んだ人も、一度試してよい

      <h2>商品を並べる</h2>
  <div class="shop">
    <div class="card">マグ</div>
    <div class="card">ノート</div>
    <div class="card">ペン</div>
    <div class="card">ふせん</div>
    <div class="card">ハサミ</div>
  </div>
        .shop { display: grid; grid-template-columns: repeat(auto-fill, minmax(140px, 1fr)); gap: 12px; }
  • repeat(auto-fill, minmax(140px, 1fr))は、「幅が140px以上のカードを、入るだけ並べる」という書き方。Simple Browserの幅を広げたり狭めたりして、列の数が自動で変わることを確認する
  • 前期第5回の@media（メディアクエリ）を書かなくても、列の数が画面の幅に合わせて変わる。DevToolsのレスポンシブモード（前期第5回）で、スマホの幅も確かめる
  • 今は「こう書くと、画面に合わせて列が変わる」と覚えておけばよい。自分の作品で使いたくなったら、制作の回で使ってよい

FlexboxとGridの使い分けを整理する（10分）

  • 一列に並べる（ヘッダー、ボタンの横並び、タグの並び）→ Flexbox
  • 格子に並べる（盤面、商品一覧）→ Grid
  • どちらでも作れる場面はある。迷ったら「縦と横の両方で揃えたいか」で決める。両方なら Grid、片方なら Flexbox
  • 組み合わせてよい：Gridで並べた商品カードの中身（名前と価格を左右に離す）を、Flexboxで作る、という使い方もできる
