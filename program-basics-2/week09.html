② 表示を関数にまとめ、クリックでデータを変える（25分）

  • データ（charactersやproducts）は、第8回のまま残す。その下の、第8回の表示のコードを全部消して、自分のジャンルのコードに置き換える（コピーしてよい）。第8回で足した表示（背景色など）がある人は、同じ行をrender（for文）の中に戻す

  • ゲーム班のコード（マスをクリックしたら、当たりかを調べ、当たりならscoreを1増やして、キャラクターを別のマスへ動かす）

    const board = document.getElementById("board");
const scoreText = document.getElementById("score");
let score = 0;
let playing = true;
const cellCount = 6;

function moveCharacter(character) {
  character.position = Math.floor(Math.random() * cellCount);
}

function hit(cellNumber) {
  if (!playing) {
    return;
  }
  for (let j = characters.length - 1; j >= 0; j--) {
    if (characters[j].position === cellNumber) {
      score = score + 1;
      moveCharacter(characters[j]);
      break;
    }
  }
  render();
}

function render() {
  board.innerHTML = "";

  for (let i = 0; i < cellCount; i++) {
    const cell = document.createElement("div");
    cell.className = "hole";

    for (let j = 0; j < characters.length; j++) {
      if (characters[j].position === i) {
        cell.textContent = characters[j].icon;
        cell.title = characters[j].name;
      }
    }

    cell.addEventListener("click", function () {
      hit(i);
    });

    board.appendChild(cell);
  }

  scoreText.textContent = `スコア: ${score}`;
}

render();
    • renderは、第8回の表示のコードを関数にして、最初に画面を空にする（board.innerHTML = "";）行を足したもの。空にしないと、呼ぶたびにマスが増え続ける
    • hitが当たり判定。押された番号（cellNumber）と、キャラクターのpositionが同じなら当たり。当たりならscoreを1増やし、moveCharacterでそのキャラクターを0〜（cellCount−1）のどこかへ動かす（同じマスに戻ることもある）。breakは「見つかったので、for文をここで終える」
    • hitのforは、後ろから探している。同じマスに2体いると、renderは後のキャラクターの絵文字を出す（前のを上書きする）ので、見えているほうを当たりにそろえるため
    • 最後のrender()は、データを変えたあとの画面の作り直し。ファイルを開いた直後の最初の表示も、この1行で出る

  • EC班のコード（商品カードに「カートに入れる」ボタンを付け、押したらcartに足して、件数と合計を出す）

    const shop = document.getElementById("shop");
const cartList = document.getElementById("cart-list");
const cartCount = document.getElementById("cart-count");
const totalText = document.getElementById("total");
const cart = [];

function showCart() {
  cartList.innerHTML = "";
  let total = 0;

  for (let i = 0; i < cart.length; i++) {
    const line = document.createElement("li");
    line.textContent = `${cart[i].name} ${cart[i].price}円`;
    cartList.appendChild(line);
    total = total + cart[i].price;
  }

  cartCount.textContent = `カート: ${cart.length}点`;
  totalText.textContent = `合計: ${total}円`;
}

for (let i = 0; i < products.length; i++) {
  const item = document.createElement("div");
  item.className = "item";

  const row = document.createElement("div");
  row.className = "row";

  const name = document.createElement("span");
  name.textContent = products[i].name;

  const price = document.createElement("span");
  price.textContent = `${products[i].price}円`;

  const button = document.createElement("button");
  button.textContent = "カートに入れる";
  button.addEventListener("click", function () {
    cart.push(products[i]);
    showCart();
  });

  row.appendChild(name);
  row.appendChild(price);
  item.appendChild(row);
  item.appendChild(button);
  shop.appendChild(item);
}

showCart();
    • cartは、カートに入れた商品を入れていく空の配列。cart.push(products[i])で、押した商品を1件、後ろに足す
    • showCartが画面の作り直し。カートを空にしてから、cartを1件ずつ見て一覧を作り、totalに価格を足して合計を出す。total = total + cart[i].price;は「今の合計に、この商品の価格を足して、合計を更新する」
    • 商品の一覧（shop）は、ファイルを開いたときに1回だけ作る。ボタンを押して作り直すのは、カートの欄だけ
  • 保存して再読み込みする。ゲーム班は、絵文字のマスを押すとスコアが1増え、絵文字が別のマスへ動けば成功。絵文字のないマスを押しても、スコアは変わらない。EC班は、「カートに入れる」を押すたびに、カートの一覧が1行ずつ増え、合計とカート件数が変われば成功

③ 動きを確かめ、データを変えてみる（15分）

  • ゲーム班: キャラクターを1体足す（第8回と同じ。前の行の末尾にカンマ）。絵文字が3つになり、当たりが3か所になる。また、一番上のconst cellCount = 6;の6を、盤面のマス数に合わせて変える（盤面を9マスにした人は9）。renderのマスの数と、moveCharacterの動く範囲が、同じcellCountで一緒に変わる
  • EC班: 同じ商品を3回押して、カートに3行できること、合計が価格の3倍になること（例: マグ800円なら2400円）を、電卓と見比べて確かめる。priceを書き換えて、合計も変わることも見る
  • ここで見てほしいのは、画面を直接書き換えていないのに、画面が変わったこと。変えたのはscoreとcartというデータだけ。データを変えて、render（showCart）を呼ぶ——これが、今日の形になる
  • うまく動かないときの確認
    • F12でConsoleタブを開き、赤い文字の行番号から見る（第7回の道具1）
    • Cannot set properties of nullは、getElementByIdの名前が、HTMLのidと1文字も違わないかを確かめる（score、cart-list、cart-count、total。EC班は、前の「骨組みの更新」をしたかも見る）
    • 押しても何も起きないときは、addEventListenerの行の後ろの});が書けているか、第8回の古い表示のコードが消さずに残っていないかを見る（古い方と新しい方が、2回表示を作っていることがある）
    • ゲーム班でマスが増え続けるときは、renderの最初のboard.innerHTML = "";が抜けている
    • EC班でカートが1回押しただけで増えない・全部同じ商品になるときは、cart.push(products[i])のiのつづりを見る。for文の中で書いているかも確認する
    • 合計がNaNや、文字がつながった数（例: 800300）になるときは、priceを引用符で囲んでいないか見る（第8回と同じ）
    • 何が起きているか分からないときは、確かめたい行の前後にconsole.log(score);（EC班はconsole.log(cart.length);）を書いて、Consoleに値が出るかを見る（第7回の道具2）

動きを足す（30分）

  • ゲーム班の例：「はじめる」で15秒のゲームにする（1秒ごとに全員が動く。15秒たつと止まる）。コードの一番下（render();の前）に足す

    const startButton = document.querySelector(".start");
let timer = null;
playing = false;

startButton.addEventListener("click", function () {
  if (timer !== null) {
    return;
  }
  score = 0;
  playing = true;
  let left = 15;

  timer = setInterval(function () {
    for (let j = 0; j < characters.length; j++) {
      moveCharacter(characters[j]);
    }
    left = left - 1;
    if (left <= 0) {
      clearInterval(timer);
      timer = null;
      playing = false;
    }
    render();
  }, 1000);

  render();
});

    playingは、「いまゲーム中か」を覚える変数。falseの間は、hitの最初のreturnで、マスを押しても点が入らない。setInterval(関数, 1000)は、1000ミリ秒（1秒）ごとに関数を動かす。clearIntervalで止める。if (timer !== null) { return; }は、「はじめる」を押しすぎて、二重に動くのを防ぐ。点を変えたい人は、hitのscore = score + 1;をscore = score + characters[j].point;にする（pointは、第8回で足した項目）

  • EC班の例：カートの取り消しボタン。showCartの中の、cartList.appendChild(line);のすぐ上に足す

        const remove = document.createElement("button");
    remove.textContent = "取り消す";
    remove.addEventListener("click", function () {
      cart.splice(i, 1);
      showCart();
    });
    line.appendChild(remove);

    cart.splice(i, 1)は、i番目から1件だけ、配列から取り除く。取り除いたあとにshowCart()を呼ぶと、一覧も合計も、自動で合う

  • EC班の例：1000円以上で「送料無料」。showCartの最後の行、totalText.textContent = ...;を、次に置き換える

      if (total >= 1000) {
    totalText.textContent = `合計: ${total}円（送料無料）`;
  } else {
    totalText.textContent = `合計: ${total}円`;
  }
  • 書き方が分からないときは、自分で書いた似た行をまねる。「クリックされたら → データを変える → 画面を作り直す」の3点セットは、どの動きでも同じ
  • 色や余白など、見た目の細かい調整は後回しでよい。今日の主役は、クリックに応じてデータが変わること
