データを扱う基礎②：フォーム入力を受け取る

Week 3 火曜 1・2限
テーマ
<input>要素から値を取得する方法、簡単なバリデーション。第2回でオブジェクトの配列に発展させたlist.htmlに、フォームから新しい項目を追加できる機能を作り、ユーザーの入力に応じて画面を変化させる練習をする
キーワード
<input>要素 / .value / addEventListener / 配列へのpush / 再描画 / 簡単なバリデーション
必要な準備
第2回で「オブジェクトの配列」版に書き換えたlist.htmlにアクセスできる状態。見当たらない・書き換えが終わっていない人は、下記「1限前半」の完成版テンプレートをコピーして使ってよい

この回のゴール

  • <input>要素の.valueプロパティで、ユーザーが入力した文字列を取得できる
  • addEventListenerでボタンのクリックをきっかけに、入力値を読み取る処理を書ける
  • 読み取った値を配列にpushし、画面を再描画できる
  • 空欄のまま送信しようとした場合に処理を止める、簡単なバリデーションを書ける

<input>要素の基本を手で書く

<input>要素を画面に置く（15分）

  • Codespacesで新規ファイルinput-demo.htmlを作り、下のコードを貼り付けて保存する
    • <!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>inputのデモ</title>
</head>
<body>
  <input type="text" id="name-input" placeholder="名前を入力">
  <button id="greet-btn">あいさつする</button>
  <p id="greet-result"></p>

  <script>
    document.getElementById("greet-btn").addEventListener("click", () => {
      const name = document.getElementById("name-input").value;
      document.getElementById("greet-result").textContent = `こんにちは、${name}さん！`;
    });
  </script>
</body>
</html>
  • Simple Browserのアドレスバーの末尾だけを/input-demo.htmlに書き換えてEnter。名前を入力してボタンを押すと挨拶が表示されることを確認する

何が起きているか（15分）

  • <input type="text" id="name-input">——文字を入力できる部品。idで後からJavaScriptから取り出せるようにする
  • document.getElementById("name-input").value——.valueプロパティで、入力欄に今入っている文字列を取得できる。.textContent（表示テキストの読み書き）とは別物であることに注意
  • addEventListener("click", ...)——前期第11回で学んだイベント処理と同じ仕組み。「ボタンが押された瞬間」に.valueを読み取っている

演習：入力欄を増やしてみる（20分）

  • input-demo.htmlに<input>をもう1つ追加し（例：好きな食べ物）、ボタンを押したときに2つの値を組み合わせて表示する
  • ヒント：<input>を追加する場合はidを別の名前にする（同じidは使えない）
  • できた人は、入力欄を空のまま送信するとどう表示されるか試してみる（次のパートで扱う「バリデーション」の必要性を体感する）

2限 前半 約50分

list.htmlにフォームを追加し、新しいお気に入りを追加できるようにする

フォーム部分をHTMLに追加する（10分）

  • list.htmlの<ul id="favorite-list"></ul>の直前に、以下を追加する：
    • <div>
  <input type="text" id="input-category" placeholder="カテゴリ（例：好きな食べ物）">
  <input type="text" id="input-value" placeholder="内容（例：カレー）">
  <input type="text" id="input-reason" placeholder="理由（例：辛いから）">
  <button id="add-btn">追加する</button>
</div>

再描画をひとつの関数にまとめる（15分）

  • 第2回で書いたfor文の再描画部分を、何度でも呼び出せる関数renderにまとめる。まず<ul></ul>の中身を空にしてから描き直す点がポイント：
    • const ul = document.getElementById("favorite-list");

function render() {
  ul.innerHTML = "";
  for (let i = 0; i < favorites.length; i++) {
    const li = document.createElement("li");
    li.textContent = `${favorites[i].category}：${favorites[i].value}（${favorites[i].reason}）`;
    ul.appendChild(li);
  }
}

render();
  • 保存してSimple Browserを更新——書き換え前と同じ一覧が表示されれば成功（render()を1回呼んでいるだけなので、見た目は変わらない）

「追加する」ボタンの処理を書く（25分）

  • render()関数の下に、以下を追加する：
    • document.getElementById("add-btn").addEventListener("click", () => {
  const category = document.getElementById("input-category").value;
  const value = document.getElementById("input-value").value;
  const reason = document.getElementById("input-reason").value;

  favorites.push({ category, value, reason });
  render();
});
  • 3つの入力欄に値を入れて「追加する」を押し、一覧に新しい項目が増えることを確認する
  • { category, value, reason }は{ category: category, value: value, reason: reason }の省略記法——変数名とキー名が同じときに使える書き方であることを紹介する
  • うまく動かないときはF12→Consoleタブでエラーを確認。よくあるミス：idのスペルミス、renderの呼び出し忘れ
2限 後半 約30分

簡単なバリデーションを追加する

空欄のまま追加できてしまう問題を確認する（5分）

  • 入力欄を空のまま「追加する」を押すと、空っぽの項目が一覧に増えてしまうことを確認する

if文で入力チェックを追加する（20分）

  • 前期第7回で学んだif文を使い、categoryとvalueが空文字列でないかを確認してからpushする。2限前半で書いたaddEventListenerのブロックをまるごと以下のコードに置き換える（そのまま追記すると、クリック時に2つの処理が同時に動いて項目が二重に追加されてしまうので注意）：
    • document.getElementById("add-btn").addEventListener("click", () => {
  const category = document.getElementById("input-category").value;
  const value = document.getElementById("input-value").value;
  const reason = document.getElementById("input-reason").value;

  if (category === "" || value === "") {
    alert("カテゴリと内容は入力してください");
    return;
  }

  favorites.push({ category, value, reason });
  render();

  document.getElementById("input-category").value = "";
  document.getElementById("input-value").value = "";
  document.getElementById("input-reason").value = "";
});
  • return;——条件に一致したらそこで処理を止め、以降のpushやrenderを実行させない
  • 最後の3行——追加が成功したら入力欄を空文字列に戻す。次の入力をしやすくする工夫
  • 空欄のまま送信するとアラートが出て追加されないこと、正しく入力すると追加され入力欄が空になることの両方を確認する

余裕があれば（5分）

  • reasonも必須にする、または「同じカテゴリは追加できないようにする」等、自分なりのチェックを追加してみる
