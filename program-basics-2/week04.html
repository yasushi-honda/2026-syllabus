JSON.stringifyとJSON.parseを手で書いて理解する

配列をそのまま保存しようとすると失敗することを確認する（10分）

  • Codespacesで新規ファイルstorage-demo.htmlを作り、下のコードを貼り付けて保存する

    <!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>localStorageとJSONのデモ</title>
</head>
<body>
  <button id="save-btn">配列を保存する</button>
  <button id="load-btn">保存した配列を読み込む</button>
  <p id="result"></p>

  <script>
    const colors = ["赤", "青", "緑"];

    document.getElementById("save-btn").addEventListener("click", () => {
      localStorage.setItem("colors", colors);
      document.getElementById("result").textContent = "保存しました（そのまま保存）";
    });

    document.getElementById("load-btn").addEventListener("click", () => {
      const loaded = localStorage.getItem("colors");
      console.log(loaded);
      document.getElementById("result").textContent = loaded;
    });
  </script>
</body>
</html>
  • Simple Browserのアドレスバーの末尾だけを/storage-demo.htmlに書き換えてEnter。「配列を保存する」→「保存した配列を読み込む」の順に押し、F12→Consoleタブを見る
  • ["赤","青","緑"]ではなく赤,青,緑という文字列になってしまうことを確認する——localStorage.setItemは渡された値を自動的に文字列へ変換して保存するため、配列としての形（[ ]や引用符）は失われてしまう

JSON.stringify / JSON.parseで正しく変換する（20分）

  • save-btnとload-btnのイベント処理を、以下のコードに書き換える： 
    document.getElementById("save-btn").addEventListener("click", () => {
  localStorage.setItem("colors", JSON.stringify(colors));
  document.getElementById("result").textContent = "保存しました（JSON.stringifyで変換）";
});

document.getElementById("load-btn").addEventListener("click", () => {
  const saved = localStorage.getItem("colors");
  const loadedColors = JSON.parse(saved);
  console.log(loadedColors);
  document.getElementById("result").textContent = loadedColors.join("、");
});
  • JSON.stringify(colors)——配列やオブジェクトを、保存できる形の文字列（JSON形式）に変換する
  • JSON.parse(saved)——JSON形式の文字列を、元の配列やオブジェクトに戻す。stringifyとparseは逆の変換をする対の関数であることを強調する
  • 保存→読み込みを試し、今度はloadedColorsが本物の配列として扱える（.join("、")が使える）ことを確認する

list.htmlに保存処理を追加する（20分）

  • list.htmlに戻り、const favorites = [...]の下、const ul = ...の上に、保存用の関数を追加する：

読み込み処理を作り、「消えない」を実現する

ページを開いた瞬間に読み込む関数を作る（20分）

  • saveFavorites関数の下に、読み込み用の関数を追加する： 
    function loadFavorites() {
  const saved = localStorage.getItem("favorites");
  if (saved === null) {
    return [
      { category: "好きな食べ物", value: "カレー", reason: "辛いものが好きだから" },
      { category: "好きな色",     value: "青",     reason: "空の色だから" },
      { category: "好きな音楽",   value: "J-POP",  reason: "歌詞が心に残るから" },
      { category: "好きな場所",   value: "図書館", reason: "静かで集中できるから" }
    ];
  }
  return JSON.parse(saved);
}
  • const favorites = [ ... ];の行をまるごと削除し、代わりに以下の1行に置き換える： 
    let favorites = loadFavorites();
  • constからletに変わっている点に注意——favoritesを後から別の配列（読み込んだデータ）に入れ替えるため、再代入できるletにする必要がある
  • saved === null——「まだ一度も保存されていない（localStorageが空）」場合の判定。初めてlist.htmlを開いた人にも、最初の4件が表示されるようにするための工夫
