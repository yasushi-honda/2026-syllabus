データを扱う基礎①：オブジェクトと配列の発展

Week 2 火曜 1・2限
テーマ
複数の情報をひとまとめにするオブジェクトの書き方を学ぶ。前期第9回で作ったlist.htmlの配列（favorites）を、文字列の配列からオブジェクトの配列に発展させる
キーワード
オブジェクト / プロパティ（キーと値） / ドット記法 / オブジェクトの配列 / テンプレートリテラル / for文との組み合わせ
必要な準備
前期第9回で公開したlist.html（favorites配列でお気に入りをリスト表示するページ）にアクセスできる状態。前期「プログラム基礎 I」を受けていない人・list.htmlが見当たらない人は、下記「1限前半」の雛形テンプレートをコピーして作成すればOK

この回のゴール

  • オブジェクトが「複数の情報をひとつの変数にまとめる入れ物」であることを自分の言葉で説明できる
  • { key: value }の書き方でオブジェクトを宣言し、ドット記法（obj.key）でプロパティを取り出せる
  • 配列の中にオブジェクトを複数入れる「オブジェクトの配列」を書ける
  • for文と組み合わせて、オブジェクトの配列の中身を画面にリスト表示できる

前期第9回のlist.htmlを開き直す（10分）

  • python3 -m http.server 8000 を起動し、第1回（前期）と同じ手順で「ポート」タブ→「エディターでプレビュー」→ Simple Browserを開く（表示されるのはindex.html）
  • index.htmlの「お気に入りリストを見る」リンクからlist.htmlに移動する。リンクが見当たらない場合は、アドレスバーの末尾だけを/list.htmlに書き換えてEnter
  • favorites配列（文字列の配列）と、for文で<li>を並べる仕組みを見直す
前期「プログラム基礎 I」を受けていない人・list.htmlが見当たらない人へ: 下のテンプレートをコピーして、リポジトリのルートに新規ファイルlist.htmlを作成してください（手順は前期第9回と同じ——ファイル一覧で右クリック→New File）。中身は前期の受講者が第9回で作った状態と同じ「文字列の配列をfor文でリスト表示するページ」です。保存してSimple Browserで開き、4項目の箇条書きが表示されればOK——これを土台に、このあとの手順を一緒に進められます。GitHubリポジトリ自体がまだない場合は、先に担当教員に声をかけてください。 
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>お気に入りリスト</title>
</head>
<body>
  <h1>私のお気に入り</h1>
  <p>配列に入れたものを <code>for</code> 文で全部表示します</p>
  <ul id="favorite-list"></ul>

  <script>
    const favorites = [
      "好きな食べ物：カレー",
      "好きな色：青",
      "好きな音楽：J-POP",
      "好きな場所：図書館"
    ];

    const ul = document.getElementById("favorite-list");

    for (let i = 0; i < favorites.length; i++) {
      const li = document.createElement("li");
      li.textContent = favorites[i];
      ul.appendChild(li);
    }
  </script>
</body>
</html>

「もっと情報を持たせたい」という要求から限界を体感する（20分）

  • 「好きな食べ物：カレー」という文字列だけでなく、「なぜ好きか」という理由も一緒に持たせたいとする
  • 素朴に試すなら、文字列を長くする（"好きな食べ物：カレー（理由：辛いから）"）か、別々の変数に分ける（food1, reason1, food2, reason2...）しかない
  • 前期第9回で「同じことを10回書くのは面倒」と感じてfor文にたどり着いたのと同じように、「1つのものに複数の情報をまとめて持たせたい」という感覚が、今日学ぶオブジェクトが登場する理由
配列は「同じ種類の物の集まり」、オブジェクトは「1つの物が持つ複数の情報」: favorites配列は「お気に入りの一覧」という同じ種類の集まりでした。今日学ぶオブジェクトは、「1つのお気に入り」が持つ「カテゴリ」「内容」「理由」のような複数の情報をひとまとめにする書き方です。
1限 後半 約50分

オブジェクトの基本を手で書く

オブジェクトの書き方（15分）

  • オブジェクトは波括弧{ }で「キー：値」の組を並べて書く。F12の Console タブに直接打ち込んで確認する： 
    const me = {
  name: "本田 太郎",
  favoriteColor: "青",
  hobby: "読書"
};

console.log(me.name);          // "本田 太郎"
console.log(me.favoriteColor); // "青"
console.log(me.hobby);         // "読書"
  • 注意点3つ：
    • キー（nameなど）はクォート不要、値が文字列なら""で囲む
    • プロパティの取り出しはドット記法 obj.key——配列のarr[0]とは書き方が違う
    • キーと値の組の数はいくつでもよい（1個でも10個でも）

プロパティを書き換える（10分）

  • me.hobby = "映画鑑賞";のように代入で書き換えられることを確認
  • console.log(me);でオブジェクト全体をログに出し、Consoleの表示（{name: "...", favoriteColor: "...", hobby: "..."}）を観察

演習：自分の自己紹介オブジェクトを作る（25分）

  • F12のConsoleで、自分自身を表すオブジェクトを作る。プロパティは最低4つ（例：name, favoriteColor, hobby, dreamなど自由に）
  • 作ったらconsole.log(自分の変数名.プロパティ名)で1つずつ取り出して表示できるか確認
  • 個人情報（本名・住所・電話番号）は書かない原則は授業共通。「クラスメイトに見せてもOKな範囲」で書く
  • ペアで画面を見せ合い、相手のオブジェクトから1つプロパティを読み上げてもらう（任意）
休憩 10分
2限 前半 約50分

list.htmlを「オブジェクトの配列」に発展させる

「配列の中にオブジェクトを入れる」という発想（10分）

  • 配列は「同じ種類の物」を並べる入れ物。その1つ1つをオブジェクトにすると、「情報が複数ある物の一覧」が作れる
  • これが「オブジェクトの配列」——ゲーム制作でもECサイト制作でも、後期の作品づくりで繰り返し使う形

list.htmlのfavorites配列を書き換える（30分）

  • 前期第9回のテンプレ例（favoritesは文字列の配列だった。すでに自分の項目に書き換え済みの人は、以下は「型」として読み、自分の項目でそのまま置き換えて考える）： 
    const favorites = [
  "好きな食べ物：カレー",
  "好きな色：青",
  "好きな音楽：J-POP",
  "好きな場所：図書館"
];
  • 各要素をオブジェクトに包み、オブジェクトの配列に書き換える（自分の項目がある人は、その内容で同じ形に変換する）： 
    const favorites = [
  { category: "好きな食べ物", value: "カレー" },
  { category: "好きな色",     value: "青" },
  { category: "好きな音楽",   value: "J-POP" },
  { category: "好きな場所",   value: "図書館" }
];
  • for文の中身も、配列の要素（オブジェクト）のプロパティにドット記法でアクセスする形に書き換える。` `（バッククォート）で囲み中に${ }で値を埋め込む書き方をテンプレートリテラルと呼ぶ——複数のプロパティを1つの文字列に組み立てるときに便利： 
    const ul = document.getElementById("favorite-list");

for (let i = 0; i < favorites.length; i++) {
  const li = document.createElement("li");
  li.textContent = `${favorites[i].category}：${favorites[i].value}`;
  ul.appendChild(li);
}
  • 保存してSimple Browserを更新——書き換え前と同じ見た目（箇条書き）が表示されれば成功。データの持ち方を変えても、表示結果は変えられることを確認
  • うまく動かないときはF12→Consoleタブ。よくあるエラー：favorites[i].categoryのスペルミス、テンプレートリテラル（バッククォート` `）の閉じ忘れ

プロパティを1つ増やしてみる（10分）

  • 各オブジェクトにreason（理由）プロパティを追加： 
    { category: "好きな食べ物", value: "カレー", reason: "辛いものが好きだから" }
  • li.textContentの中身もreasonを含む形に書き換えて表示を確認する
2限 後半 約30分

自分のオブジェクトの配列に発展させる演習

各項目にreasonを追加し、項目数を整える

  • 自分のfavorites（前期第9回で書き換え済みの項目、またはテンプレのまま作業していた人は自分自身のお気に入りに書き換える）の各オブジェクトにreasonプロパティを追加する
  • 項目数が4〜6個になるよう調整する（for文はfavorites.lengthで自動追従するので、項目を増減してもfor文側を直す必要はない）

余裕があれば：プロパティをもう1つ増やす

  • 例：emojiプロパティ（絵文字1文字）を追加し、li.textContentの先頭に表示してみる
  • 「オブジェクトのプロパティはいくつでも自由に増やせる」ことを体感する
